# 第二问：稳健精度目标与两次检测的严格精度下界

日期：2026-09-13。本文是独立数学研究记录，不修改已冻结的第二问交付。以下结论仅用官方题设，不假定源位置概率分布、测向误差均匀分布或不同地点误差独立。

## 1. 题设事实与研究目标

官方 `题目与附件/B题.pdf` 第1页问题2要求：已知全向源一次示向，给出第二检测点选择策略及候选区域，以取得较好的定位效果。第2页附录2(1)给出全局测向误差界 ±1°，并指出同一地点重复检测不会改变检测误差。第3页附录2(2)、(8)、(9)给出：接收半径在1000至1500米之间；光学清除要求距源不超过20米；距源不超过5米时返回近场信息、无法获得示向。

现有 `代码/docs/第二问_结果与候选区域.md` 第9–22行已经给出稳保接收域与三圆盘交保守子域，第30–36行提出在安全域内比较定位区域、解释交会角影响，但没有求出精度最优第二点。

本记录解决两个问题：如何把“较好精度”变成对未知源位置和未来误差均有效的目标；是否可能对全部合法首测情形保证只凭两次检测就达到20米光学清除精度。

## 2. 完整的集合成员模型

令目标区域为 T=B(O,1800)，首测点为 S₁，实际返回的正常示向为 θ₁，δ=1°。记 W(S,θ,δ) 为从 S 出发、中心方向 θ、半角 δ 的闭有向角带。正常首测相容源位置为

Ω₁ = T ∩ W(S₁,θ₁,δ) ∩ B(S₁,1500) ∩ {g: ‖g−S₁‖>5}。

圆盘边界与角带边界取闭集；正常示向的5米排除区是开条件。以下上确界可用闭包计算，避免把未达到的边界误写成已达到最大值。

第二点 q 的精确稳保接收域沿用现有推导：

C_sig = ∩_{g∈Ω₁} B(g,max{1000,‖g−S₁‖})。

对 q∈C_sig，每个首测相容源都能在第二点接收到信号；第二次可能返回正常示向 φ，也可能返回 near。

正常示向 φ 之后的精确位置可行域为

K(q,φ) = Ω₁ ∩ W(q,φ,δ) ∩ {g:‖g−q‖>5}。

若未事先限制 q∈C_sig，还应显式加入 B(q,1500) 与接收成功条件；在 C_sig 内，1500米上界已经自动满足。由于接收半径未知，不能从“接收到信号”推断源距至少1000米。

第二次返回 near 时，位置可行域为 N(q)=Ω₁∩B(q,5)，其直径至多10米、最小包围圆半径至多5米，且可在 q 直接光学清除。这个分支不需要第二条示向。

## 3. 精确的最坏精度指标

对集合 A，定义

D(A)=sup_{g,h∈A}‖g−h‖，

ρ(A)=inf_c sup_{g∈A}‖g−c‖。

其中 ρ 是最小包围圆半径，直接对应最坏位置误差及能否存在一个对所有可行源都可清除的落点。定义所有可发生的正常第二示向集合 Φ(q)={φ:K(q,φ)≠∅}，则

J_D(q)=max{D(N(q)), sup_{φ∈Φ(q)}D(K(q,φ))}，

J_ρ(q)=max{ρ(N(q)), sup_{φ∈Φ(q)}ρ(K(q,φ))}。

以上外层对第二示向取上确界，已同时包含“真实源可以在 Ω₁ 任意位置”及“第二地点测向误差可以在 ±δ 任意取值”。不需要挑选一个估计中心充当真源，也不需要给未知误差补充题设未给出的概率分布。

正常分支的直径目标还能精确改写为

sup {‖g−h‖ : g,h∈Ω₁，‖g−q‖>5，‖h−q‖>5，angle(g−q,h−q)≤2δ}。

证明：两源在 q 处各自允许的第二示向区间都有半宽 δ；两个区间有交集，当且仅当两个真实方位的最小圆周角差不超过2δ。因此约束恰好表示“两种源位置能够产生同一个第二读数”。这样的点对之最大距离就是某个后验可行域的最大直径。角差必须按圆周处理，避免0°/360°错误。

类似地，二维最小包围圆由不超过3个支撑点确定。所以正常分支的 J_ρ 也可表为：对 Ω₁ 内至多3个点取上确界，要求它们在 q 处的方位均能被同一个宽度2δ的圆周角区间包含，然后计算这些点的最小包围圆半径。这里仍须排除距 q 不超过5米的正常分支点。

直径和清除精度应严格区分。二维有

D(A)/2 ≤ ρ(A) ≤ D(A)/√3。

因此 D≤40米只是 ρ≤20米的必要条件，并非充分条件；D≤20√3米是一个充分条件。最终判断“可保证20米清除”应计算 ρ 或等价的所有半径20米圆盘之交，不应只用直径除以2。

## 4. 第二点的可用优化形式

给定允许移动长度 L，以精度为主目标：

q*(L) ∈ argmin {J_ρ(q): q∈C_sig，‖q−S₁‖≤L}。

或给定目标精度 τ，以移动时间为主目标：

min ‖q−S₁‖/5 + 5，

s.t. q∈C_sig，J_ρ(q)≤τ。

再次检测同一频道只加5秒；这里不另加换频道费用。若目标精度约束无解，应报告“在该首测信息与移动预算下不可保证”，不能通过删掉困难源位置或假定未来测向误差较小得到看似可行的结果。

这两种形式给出移动成本与稳健精度的前沿。三圆盘交子域仍可作为容易实施的可行域，但在该子域内得到的最优仅是“对保守候选域和所定义指标的最优”，不是精确 C_sig 上的全局最优。

## 5. 定理：不存在覆盖全部合法首测情形的两测20米统一保证

**命题。** 在官方题设下，要求第二点对所有首测相容全向源保证仍有信号。则不存在一种第二点选择策略，使它对所有合法首测情形，都能仅凭首测和第二次检测保证后验最小包围圆半径不超过20米。事实上，存在合法首测情形，使任意稳保第二点都有 J_ρ(q)≥25.7295667987米及 J_D(q)≥51.4591335974米。

**证明。** 构造合法首测 S₁=O=(0,0)、θ₁=0。此时 Ω₁ 包含距离大于5米、至多1500米、方向在 ±δ 内的全部扇区；该扇区完全位于半径1800米的目标圆内。

### 第一步：任意稳保第二点都满足 ‖q‖≤1005米

对每个充分小的 ε>0，源位置 g_ε=(5+ε,0)、接收半径 R=1000 都是首测相容情形。它在首测点返回正常示向，而非 near。因此稳保要求

‖q−(5+ε,0)‖≤1000。

令 ε↓0，连续性给出 ‖q−(5,0)‖≤1000，故三角不等式给出 ‖q‖≤1005。

这个界针对精确 C_sig，未假定第二点必须在现有三圆盘交保守域中。

### 第二步：首测扇区内含一个半径超过20米的圆盘

设

a = 1500/(1+sinδ)，

r = 1500 sinδ/(1+sinδ)，

c=(a,0)。

圆盘 B(c,r) 的圆心到两条角带边界的距离均为 a sinδ=r，故圆盘位于首测角带内；又有 a+r=1500，故它位于 B(O,1500) 内。其最靠近原点的距离为 a−r，大于5米，所以所有点均允许正常首测。

δ=1° 时：

- a = 1474.270433201301米；
- r = 25.729566798699米；
- a−r = 1448.540866402602米。

### 第三步：给任意 q 构造两个无法区分的源

由于 ‖q‖≤1005<a−r，q 必在 B(c,r) 外。令

u=(c−q)/‖c−q‖，g₋=c−ru，g₊=c+ru。

这两点都在首测相容圆盘内，间距为 ‖g₊−g₋‖=2r。它们相对 q 的位移分别为 (‖c−q‖−r)u 与 (‖c−q‖+r)u，两个系数都为正。因此两点从 q 看具有**完全相同的真实方位**，无需使用第二次的±1°误差就无法区分。

两个源到 q 的距离均至少为

a−r−1005 = 443.540866402602米 >5米，

因此两个假设在第二点都返回正常示向，不会被 near 分支区分。

对两个假设均选择合法的共同接收半径 R=1500。两源到首测点的距离不超过1500。由于 q∈C_sig，两源到 q 的距离也不超过 max{1000,‖g±‖}≤1500。因此两处均有信号。两源在首测点的真实方位均在 ±δ 内，可分别选择合法首测误差使实际首测读数都是0；第二地点选择0误差，使第二读数也完全相同。题设没有要求不同地点的误差相等，故这种构造符合误差条件。

同一完整观测历史后，可行域同时包含 g₋ 与 g₊，故其直径至少2r，任何覆盖它的圆半径至少r。由于 r>20，证明完成。

**适用范围。** 这是关于“全部合法首测情形”的统一保证不可能性，且甚至允许采用完整的精确安全域。它不表示每个首测情形都无法达到20米；当首测角带受到目标圆边界、先验信息或既往观测充分裁剪时，特定情形可以更容易。它也不排除平均意义上表现良好、某些误差实现下达到20米，或增加第三测/近场观测后达到20米。本定理不是实际最坏误差的紧下界，不能把25.7296米声称为已经可以达到的最优值。

## 6. 可复查的构造数值

`inradius_certificate.json` 保存常数及3个第二点的不可区分源对。默认 q=(600,300) 的构造为：

g₋≈(1449.933790780174, 8.350954634945)，

g₊≈(1498.607075622428, −8.350954634945)。

两者首测真实方位分别约0.3299938024°与−0.3192761537°，均可产生首测读数0°；在 q 处真实方位同为−18.9393116972°；距 q 分别约898.5803327318米与950.0394663291米，故不仅 R=1500 合法，两者此处也都在1000米内。两源距离约51.4591335974米。这是构造性反例，不是模拟器案例、真实测试结果或统计性能估计。

JSON使用浮点计算，个别理论边界会出现如1500.0000000000002的舍入值；合法性以第五节解析恒等式 a+r=1500 为准。

## 7. 有限计算如何给出保守保证

以下是供数值研究实施的建议，不声称本记录已完成全局求解。

1. 对精确圆弧先验，可直接计算圆弧与角带边界的交；也可以用外切多边形包住先验圆域。外包只会放大位置可行域，因此由外包得到的最坏直径或包围圆半径是保守上界；不能用内接多边形冒充保证。
2. 对第二示向 φ 做网格时，单独取网格最大值只是连续最坏情形的下估计。若每个真实示向距最近网格中心至多 h/2，则以半角 δ+h/2 在每个网格中心计算，可包住整个网格单元内所有半角 δ 的真实角带。对这些放宽角带取最大值，可得连续示向最坏误差的保守上界。须完整覆盖所有可发生的第二示向圆周区间，正确处理角度换向。
3. 对给定 q，可用显式不可区分源对取得精度下界，用外包先验和放宽角网格取得上界；上下界夹逼可给出可复查精度证据。第二点 q 本身若只作离散枚举，只能报告候选集合最优；需要覆盖空间的分支定界或其他全局证书才可声称连续域全局最优。
4. 清除相关结论使用最小包围圆半径。两点最远距离只能给出下界，三个点形成锐角三角形时，所需覆盖半径可能严格超过直径的一半。

## 8. 当前可采纳结论

保留已有稳保接收域，将“候选点评分”补成 J_ρ 或 J_D 的完整未来观测最坏目标，在同一移动预算下比较候选。论文可以加入第五节不可能性定理，说明第二问合理目标是保证接收并尽量收缩位置不确定性，而非承诺任意初始情况只凭两次测向即可清除。具体数值最优点应等待独立数值优化和精度认证，不能由一阶交会角公式直接宣称。
