# E1 开放研究计划

观察：S1的Q3/Q4移动约占74.08%/71.86%。Q4的完整任务开放路线把发现16频道后可能被取消的站点视为固定必达；上一阶段 origin_cluster 及部分16源案例存在退步。旧图 CONDITIONAL_DISCOVERY_ROUTE_PROPOSED 尚未实施。第二候选 JOINT_CLEAR_ROUTE_PROPOSED 仍只优化单个clear落点，没有联合优化多个服务区域。

R1预计改变：用固定几何假说估计已扫/未来站点的发现覆盖概率；基于已发现频道数计算“总数为16”的规划后验，对路线中条件取消的后续站点计期望路径。只改变访问顺序；真实覆盖点、未清源、50h保护和退出证书原样保留。对照固定S1，包含一个上界乐观代理以诊断概率建模是否过弱。开发只使用本地新分配种子，不修改既有评分。

后续由实际失败与瓶颈决定：若R1有效但排序脆弱，验证信息状态与路由收益来源；若结构不合适，则转向多凸服务区的联合连续选点。研究停止不按固定轮次或失败次数，不将代理下降当成整局收益。

R3实验前：在12个新种子44000036..44000047、两题各144案例上比较S1、固定原完整任务序的联合落点、对原6条顺序候选分别联合落点后择优。对于围定圆半径<20m且<=32顶点的待清源，以所有顶点20m圆交集为可行动区，交替3次单点两边路径最小化；站点和未认证源中心固定。真实当前动作仍复查全部顶点20m覆盖，保留原候选落点并择固定当前+下一点费用更低者。该优化不会增加固定顺序代理长度，但未来测量/调度会改变任务与地点，因此整局收益必须实测。

R4实验前：新种子44000048..44000063，两题各192案例，对照S1、自身R1、预计入口/中心出口有向服务块。只对一次bearing且半径超过试清阈值的源，在预计上个任务中心位置调用未修改的父second_point来预估入口，将到入口+入口到中心的内部路线费用纳入有向距离矩阵；真实动作和观测更新仍父方法。反转路线必须计所有内部有向边，不套对称2-opt公式。只改规划代理，入口后的位置/可见性、共享补测和后续清除还未知，因此不是精确服务成本或下界。按完整分题均值选，不按场景挑结果。

R5实验前：R4两题明显增加移动后，针对性只给第一任务计现有信息下的入口→中心成本，后续仍用中心以避免提前固定将被共享补测改变的入口。新种子44000064..44000079，两题各192案例对S1与R1。此假设若仍无实际收益，本轮入口/服务块路线代理收束，保留负证据，不再扫权重。
