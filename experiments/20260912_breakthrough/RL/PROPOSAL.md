# 从“模仿 C7 排序”转向“学习何时替换一次源服务”

研究截止：2026-09-12。版本：v2，已回应协调者三轮审阅，待最终验收。状态：**方案，不是已实现、已训练或已取得收益的方法**。本轮环境执行数、反事实训练分支数、模型更新数均为 0；只做源码阅读、一级来源获取和纸面/合成合同检查。

交付导航：[完整实现合同](implementation_spec.md) · [质疑与修订记录](review_log.md) · [来源账本](literature.json) · [逐篇分类/阅读边界](LITERATURE_MAP.md) · [来源审计](SOURCE_AUDIT.md) · [合成检查](contract_check_results.json)。为便于仓库差异审阅和追溯，本方案选择 Markdown；这不是用户指定的格式。旧 [41 篇统一审阅稿](../../20260911_rl_research/RESEARCH_PROPOSAL.md)完整保留，本稿是负结果后的增量方案，不替换或缩减旧综述。

## 1. 建议验收什么

建议批准的下一步不是“把 PPO 训练更久”，而是一个先验证余量、再训练的小型新机制：

> 保留 C7 的任务选择规则；只在 Q4 的源服务入口，学习是否把 C7 原本的整段服务替换为一个新的测量/清除操作，然后立即重规划。干预改变真实观测后，后续任务序列可以改变。训练时，从同一合法历史对各选项执行完整续局，学习它们相对当前冻结策略的真实剩余成本差。

名称暂定 **BC-RPI：Budgeted Counterfactual Rollout Policy Improvement，带干预预算的反事实 rollout 策略迭代**。这是使用模拟器完整回报作监督信号的近似策略迭代，不是 PPO，不是纯离线 RL，也不是从零学习物理。第一轮本质上是反事实监督门控；只有后续“当前策略诱导状态 + 当前策略续局标签”的迭代超过同预算固定教师续局基线，才归因于迭代 RL。

首版只影响 Q4，每局至多 2 次服务替换；Q3 直接保留执行时最新的非 RL 最佳版本。C7 是机制锚，**最终晋级还必须胜过第六阶段最终最优 Q4 候选**，不能只胜旧 C7。教师实现一旦更换，必须重新通过未干预等价门，不能静默切换源码。

是否值得做，分三个可证伪问题：

|假设|验证方式|否定或停止条件|
|H1：新的操作空间确有整局余量|零训练阶段，在预登记训练诊断 world 上真实完成“至多 1 次干预的有限类事后最优”及“至多 2 次的贪心闭环 oracle”|两者相对 C7 的 Q4 均值改善都不足 2%，停止本动作空间；这不是所有 RL 方向被证伪|
|H2：余量可从公开历史学到|对不可供拟合的 world 测量预测改进与实际配对改进；并独立运行完整部署策略|首轮/后续最多三轮仍无合格开发提升，放弃该方向；不能用 oracle 的高收益掩盖部署无收益|
|H3：策略迭代本身有价值|同预算固定 C7 续局监督门控，与更新续局策略的 BC-RPI 比较|若 PI 没有额外收益，保留更简单的监督门控，明确不宣传 RL 增益|

这里 2% 是研发门槛，不是论文定理，也不是预测效果。H1 的 oracle 使用训练 world 的隐藏状态作事后评估，**不可部署、不是泛化结果**；二干预贪心 oracle 也不是该动作类的全局最优上界。单个状态的最优改进不得相加充当整局改善。

## 2. 为什么改变学习对象

### 已核实的本地事实

当前机制锚是 `20260911_stage4/combination/geometry_fusions/C7_both.py`，SHA256 为 `cf37866829b9c6f376895075e819a732939e6fa8ad6d8d6297a151d7a213dcb3`。其历史共同 4800 个已暴露案例 Q3/Q4 为 235.876946/456.111821 秒/源；不是官方成绩。本轮非 RL 候选仍在独立迭代，因此未来执行时另冻结 `best_at_execution` 对照。

旧 RL 不是在学 C7 内部所有控制。`core/engine.py::build_snapshot` 只提供 `station/source/fallback` 宏任务；源候选的 `target` 通常只是可行区域中心，真正执行 `s.localize(ch)` 时会包含额外测量、失败清除、救援、跨频道补测。旧 `16 + 20×12 + K×16` 特征没有完整编码 bearing、no_signal 和失败清除的形状/时间历史，且未证明 Markov。

旧共同选择集每题 96 world，三个初始化先在同 world 内平均，得到：

|方法|Q3 秒/源|Q4 秒/源|相对本批 C7 变化|
|---|---:|---:|---|
|C7|235.926912|439.890（约）|本批对照，与历史 4800 不同|
|PPO|244.977|464.389|慢 3.836% / 5.569%|
|约束 Q|244.157|468.386|慢 3.488% / 6.478%|

5,760 次选择执行全部正常全清，但均未晋级。旧完整审计为 12,609 次任务、3,840 个独特 world、3,968,212 次业务调用，状态 `consistent_complete`。这些数来自已保存的 [执行报告](../../20260911_rl_execution/REPORT.md)与[完整审计](../../20260911_rl_execution/verification/full_audit_v1/REPORT.md)，本轮没有重跑它们，也没有把旧选择集当新测试。

Q 的 69,512 次部署决策中，41.19% 的支持集合只有 teacher，70.15% 与 teacher 相同；训练中 1,177/3,072 局因探索直接选择 fallback，尾段占训练虚拟时间 55.46%。这提示“候选余量、表示损失、采样浪费”值得诊断，**不能证明其中任一项是退步的唯一原因**。简单移除探索、增加 GRU 或多训练，没有现成的因果证据。

### 本次推断与机制选择

本题移动和计费规则已知，真正难的是在有界、同址固定的测角误差与 Q4 不确定可见性下，判断额外观测能否省掉后续动作和移动。全局调度已经经过很多轮路径与几何优化；继续模仿其次序，可能先损失教师精细行为，却没有得到新的物理动作。我们因此把学习对象下移一层：**服务终止/重规划时机和主动落点**。

这是有依据的选题推断，尚未证明 C7 的“瓶颈”就在此。H1 专门负责否定这项推断。历史路径图中主动信息、多频道联合第二测点、模态选择均有失败例；本方案与它们的差异是用真实完整续局标签衡量任务成本，而非只用面积、熵或局部半径下降代理，但仍可能失败。

## 3. 新机制怎样工作

### 3.1 不恢复任意 Python 调用栈

只在现有 `core/engine.py::run_episode` 已自然返回的全局边界决策。全局任务仍由原 `_teacher_task` 选择；若选择 station，原样扫描；若选择 source，提供以下有限选项：

1. `teacher_service`：完整原样调用 C7 的 `localize(ch)`。
2. `clear_center` / `clear_nearest_cover_cell`：在公开几何构造的点尝试一次清除，然后返回全局边界。
3. `measure_center`、原第二测点、镜像点、可见历史点与当前位置中点、左右横移点：执行 C7 的测量方法并返回边界。

最多 9 个选项，非法或重复选项去重，教师选项永不由统计门控删掉。精确公式、合法性、预算更新和 payload 见实现合同。

**一次 controller operation 不一定是一条请求。** 当前 Q4 `measure` 在 `near` 后会自动 `clear`；局部服务内 `_active_target` 非空还可能跨频道补测。新的入口要求 `_active_target=None`、`_sharing=False`，且教师冻结配置本来就有 `e2_same_here=False`；不通过改变配置来制造等价。仍以 `event_range` 内全部真实请求计费，不根据函数调用数推算时间。Q3 的 `same_location_clear=True` 可产生更多连清，所以首版不介入 Q3。

所有选项先承接同一个 teacher `controller_patch` 和 `route_successor`。新操作不伪造 `_e2_progress`，不标记 station 已扫描，不修改退出证书。没有在原 `localize` 中抛异常后再随意 `solver.run()` 的“恢复”。

### 3.2 可观察状态与可靠几何分离

在线 actor 仅接收公开请求/响应导出的状态：完整账本在执行器保存；网络看主动频道历史 token、保守位置多边形的编码、20 个频道摘要、计划后继及剩余干预槽位。加入 `direction/no_signal/failed clear` 的位置和顺序，bearing 以相对角的 sin/cos 编码，保留重复同址信息。

使用“机器狗当前位置为原点、主动频道首个正 bearing 为朝向”的局部坐标，同时保留目标圆圆心在该坐标中的位置，避免丢掉边界信息。旋转等变测试只验证表示和动作变换，不假定本地网格/哈希误差场在旋转后分布不变；不做未经建模的旋转标签增强。

网络特征不含真实源数 N、源位置、真实半径、真实方向/类型、seed、scenario、world ID、成绩或特权奖励。真实时钟只留给期限守卫，不进入价值网络。20 频道集合按共享编码处理，频道数字本身不当空间特征；换频与“是否当前频道”是合法输入。

压缩表示不被称为精确 belief 或 Markov 状态。有限 token/顶点编码可能丢信息；可靠证书始终使用原完整几何和账本，不能由神经网络判定“无源”。

### 3.3 同世界完整反事实，而非虚构标签

令 h 为公开历史及控制器状态，b 为剩余干预槽位，w 为仅评测进程可见的世界，π_j 为本轮冻结部署策略。训练端在相同 `(w,h,b)` 上比较动作 a 与 `a_ref=π_j(h,b)`，每个分支都运行到真实终端，后续策略都是同一 π_j：

\[
C_j(w,h,b,a)=\frac{\Delta T_{a\to\mathrm{terminal}}}{1000N_w}+100\,1[\mathrm{failed}],\qquad
y_j=C_j(w,h,b,a_{ref})-C_j(w,h,b,a).
\]

未改变的前缀在成本差中抵消；完整整局报告仍加回前缀。T 包含 near 自动清除、以后所有补测、路由和 fallback；真实失败不是便宜的截断。N 只由终局标签进程填入，绝不进入 actor 或“previous reward”。`γ=1`，不按宏动作数/持续时间折扣，也不加熵或面积奖励。

关键预算语义：两个分支起点同为 b；若某分支选的是非 teacher，则自身 b 减 1，否则不减。`a_ref` 也可能是一个干预，不能假设 reference 永不耗槽，更不能强行让两边都续 `b-1`。这正是剩余干预机会的成本。

本地 `error(x,y,ch)` 是同址固定函数，fork 必须保留同一 seed/误差场、清除状态与整数微秒账本；不在分支中重新抽误差，不同频道共享场不能独立重采样。候选生成器只能接收公开状态，不能接触 fork 或 `LocalEnv.error`。真实模拟器状态只在隔离采样进程存在，部署不具备 fork API。

### 3.4 从一轮监督到策略迭代

第一轮 π_0=C7；学习各操作相对 C7 的完整回报差。后续每轮先冻结 π_j，在其诱导状态上收集新分支，并对抽中的旧公开历史重新用 π_j 续局。旧标签若 continuation SHA 不同，不能直接拼成当前标签；可以保留作历史研究，不能假装同一 Q。

拟合器为 61,121 参数的轻量集合编码 MLP；三个独立初始化分别训练，不把三者自动组成 ensemble。首版只用 world 等权、以 s=0.002 归一的无量纲 Huber 配对回报回归，排序仅列为消融，避免未归一的回归和排序尺度失衡。不需要 PPO 的旧 logprob，也没有离线 TD 估值自举。部署只加载当前冻结模型和 A0，不递归运行旧策略链；通过固定经验残差门槛才改变 C7 动作，b 用尽后精确回 C7。每个候选 π_{j+1} 必须独立完整闭环开发验证，单步预测变好不够。

此设计受 [NRPI/AggreVaTe](https://arxiv.org/abs/1406.5979) 的 cost-to-go 策略迭代与 [LOLS](https://proceedings.mlr.press/v37/changb15.html) 的 roll-in/roll-out 区分启发，不等同这两篇算法：我们有变长宏操作、部分观测、固定误差场、干预预算、有限状态采样和经验门控，不继承它们的无条件改进定理。

## 4. 安全与“改善”是两回事

可靠层保留：四接口白名单、C7 几何外包、发现覆盖账本、合法 clear 成功确认、退出证书、每次请求守卫、有限无进展检测、不可逆独立 fallback。现有 53,000 秒 fallback 预留只是在题设理想响应下的虚拟时间构造；官方网络和现实计算没有确定上界，所以不能宣称现实 1200 秒内无条件全清。

干预每局最多 2 次，且每次先消耗一个槽位再执行。若操作不产生新正观测、几何收紧或清除进展，该频道下一次服务强制走 teacher；槽位不会因 no_signal/失败 clear 退回。C7 的正常接管仍保留。统计门控不替代这些完成性约束。

校准 world 与拟合、开发/选择全部隔离。先冻结网络和其每状态会选择的 a*，只收集 a* 与 A0 的同 π_j 完整tail；按 world 聚合选中动作的最大乐观残差，其 90% 分位数作为经验保守裕量，不宣称校准全部K动作。不足样本/特征缺失默认 teacher。该裕量不是后验概率，3 个初始化也不是置信区间，有限样本经验门控不是 [SPIBB](https://proceedings.mlr.press/v97/laroche19a.html) 的有限 MDP 保证。尤其 π_{j+1} 改变访问分布后，不能搬用 π_j 校准状态上的覆盖率当闭环保证。

## 5. 验收和停止

### 数据分层

- 已有 4800 案例、旧 RL 训练/选择及本轮算法研发结果：已暴露背景与兼容回归。
- 新训练诊断：专门做 H1、接口/资源预检，不用于最终泛化。
- 拟合/拟合内验证：每轮 36 个 world 固定为 24 fit + 12 fit_val；第二、三轮为 12 旧 fit + 12 新 fit + 12 新 fit_val。fit_val 永不用于梯度，旧 fit_val 不改成 fit；每条轨迹/所有分支同 world 同分区，不按 snapshot 随机拆分。
- calibration：只决定预登记经验裕量，不训练表示或挑架构。
- development/selection：选择迭代版本、核查三初始化，结果含选择偏差。
- sealed final：用户接受实施并冻结所有代码、权重、阈值后才生成/打开；失败后若修方法，必须重新定义新的最终验证，不能把原集继续叫密封。
- Windows 官方演练与正式测试：另有权限与通信验收，绝不由本地替代。

### 晋级门槛

所有登记 world 均正常全清、无未记账/未决失败；Q3 最新非 RL 入口保持逐请求语义不变。Q4 相对 C7 与 `best_at_execution` 均改善至少 2%，配对均值差的分层 bootstrap 区间上界小于 0，至少 2/3 独立初始化方向一致。每个场景的均值退步超过 2% 则不直接推广；保留最差局、P95/P99、fallback 率及所有失败。

开发区间只是选择证据。最终只允许一个冻结冠军策略对两个冻结对照进行预登记检验；为两对照比较采用 Bonferroni 单侧 97.5% 区间，另报告描述性双侧区间。world 是重采样单位；重复初始化和分支不是独立样本。

要声称“迭代 RL 优于一次监督”，还需同实际标签/调用预算的固定 C7 续局基线：相同新 world、动作生成器、模型、训练更新预算与校准规则，唯一改变为是否更新续局策略及其诱导状态。若只胜“第一轮小数据模型”，不能排除额外数据/算力的作用。

连续三轮未达到“相对当前已保留候选确有开发改善”的门槛即停止同一机制；调 checkpoint 不算三轮，不可改名重置失败计数。有真实改善可继续，但仍受用户最终批准的总资源预算约束；预算不足先交已完成证据，绝不丢弃费用或自动扩大额度。

## 6. 拟议资源上限与分阶段授权

**本轮未执行这些预算。** 下一轮应先仅批准 G0/G1 零训练门；通过后才决定是否执行研发训练包。原 v1 把最终验证塞入研发 500 万调用上限，与拟议规模不兼容；现拆为研发至多 500 万和另行授权的发布验证至多 300 万，不能默认一起启动。

|阶段|计划规模/目的|业务调用硬上限|
|G0/G1：等价、fork、headroom|48 个等价检查 world；24 个 Q4 headroom 训练诊断 world；无网络拟合|350,000|
|G2-P：BC-RPI 最多三轮|每初始化每轮 36 个 world、每 world 至多 4 个边界、K≤9；3 初始化；第 2/3 轮含旧历史刷新|1,500,000|
|G2-S：匹配预算的固定教师续局基线|相同候选、world 配方、实际标签与调用预算；若 G2-P 完全无益可省略，但不可声称 PI 因果增量|1,500,000|
|校准与必要反事实消融|各轮 24 个独立 Q4 calibration world/初始化，最多 2 个状态/局；必要消融优先|550,000|
|开发闭环及有限消融|同 120 development world 对所有登记候选；精确缓存复用对照，不含 4800 暴露回归和 sealed final|1,100,000|
|研发合计|不是必耗额度；任一阶段预算耗尽不证明无余量|5,000,000|
|独立发布验证，另行授权|冻结冠军后 4800 暴露兼容回归、1200 新 Q4 world×3 策略和 96 次 Q3 接口等价运行|3,000,000|

研发另设上限：40,000 次实际 full/suffix rollout 执行、累计采样/拟合 6 小时墙钟、8 GiB 原始研究数据、16 GiB 进程 RSS；任一先到即不再启动新分支。独立发布验证另申请至多 8,496 次完整运行、3 小时墙钟和 4 GiB 原始数据，RSS 同为 16 GiB。已有单请求/整局预留合同沿用并单独记录，不在局中截断让成本“变便宜”。36×4×9×3×3=11,664 是 G2-P 含 fit_val 的最大分支数，不是独特 world 数，也不包含校准和基线。期望时长/最终能完成多少，要由 G0/G1 实测确定，不能把历史 CPU 时间或论文 GPU 小时照搬。

以仅供规划的历史约 263 次业务调用/完整局估算：开发最多 3轮×3初始化×120局×2方法臂=2,160 候选局，加 240 对照局和 240 有限消融局，共约 694,320 调用；发布验证 (4,800+1,200×3+96)×263≈2,234,448 调用。这不是成本上界，分支重放和异常另实记。完整算术、缓存资格和不足时停止规则见实现合同 G5；不以选有利子集满足预算，最终样本未完成时只能报告未决。

部署工程目标：batch=1，从候选/特征构建到操作前的完整 P95/P99、超时和峰值内存；P99≤100 ms 是本方案设计门槛，不是已测结果或用户题面要求。网络和几何失败均退到 teacher/独立 guard，不能生成“免费移动”。

## 7. 文献分类与本题迁移

本次来源账本共 16 个去重条目：9 篇核心指定章节阅读，7 篇扩展；“核心”不等于逐页读完全部附录。与先前完整保留的41篇有9篇同身份，本轮新增7篇，身份并集48篇；不是“新增16篇”或“48篇全部本轮深读”。数量由账本与审计复算。主要近期扫描窗口为 2024-01-01 至 2026-09-12，必要机制祖先追溯至 2011。未完成领域穷尽或首创新颖性检索。

分类轴为“对策略改进承担的主机制职责”；同一论文只取一条主路径，次级标签表达交叉。

```text
利用强基线改善部分可观测控制
├─ 控制对象的分解
│  └─ 保留解析控制并学习动作残差 → S05 Residual RL
├─ 真实任务损失驱动的策略改进
│  ├─ 在诱导状态上聚合动作示范 → S01 DAgger
│  ├─ 查询当前策略完整 cost-to-go → S06 NRPI / AggreVaTe
│  ├─ 参考/学得策略续局的区分与混合 → S02 LOLS
│  └─ 可微 cost-to-go 优化 → S03 AggreVaTeD
├─ 主动信息决策的表示与动作约束
│  ├─ GP 图、Pointer 与预算约束 → S07 CAtNIPP
│  └─ 离线行为支持约束候选 Q → S08 OffRIPP
└─ 限制统计/执行风险
   ├─ 低支持区域复制基线概率 → S04 SPIBB
   └─ 形式规格的执行屏障 → S11 Shielding
```

### 7.1 控制对象的分解：S05

[Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201v2) 在手工控制器上叠加可学习连续控制量，采用 TD3 类更新，在 MuJoCo 与实体 block assembly 检查。正文图 3 的错位实体块实验为 residual 15/20、手工控制 2/20；这个小实验说明结构可保留、残差可以学，但不证明本题有收益。我们的动作是离散服务替换，不是把 TD3 输出加到坐标；不能沿用其稳定性表述、机器人样本效率或三小时训练预算。

### 7.2 完整任务损失：S01、S06、S02、S03

[DAgger](https://proceedings.mlr.press/v15/ross11a.html) 指出行为改变后输入分布随之改变，迭代聚合受学得策略影响的示范；实验包含 Super Tux Kart、Super Mario 和 OCR。它不是“奖励更强的 BC”，也不自动超过教师。我们借其诱导状态采样，不优化教师动作一致率。

[Ross 与 Bagnell 2014](https://arxiv.org/abs/1406.5979) 明确区分 AggreVaTe 的 expert cost-to-go 与 NRPI 的 current-policy cost-to-go；第 2.5 节还给出专家续局过于乐观的窄路反例。第 3 节是当前提案的机制祖先：通过模拟完整续局形成成本敏感训练数据。它主要提供理论框架，不是本题基准实测，也不赋予非凸网络无条件 no-regret 性质。

[LOLS](https://proceedings.mlr.press/v37/changb15.html) 进一步说明 reference roll-in 会遗漏学习策略会到达的状态，仅 reference roll-out 也可能掩盖复合错误；算法混合 reference/learned 续局。正文依存分析中，次优参考条件 learned/mixture 为 90.2 UAS，learned/reference 为 87.1；但 POS 中 reference 续局更好，不能把混合说成处处获胜。本提案首版选完整冻结 π_j 续局以确保标签语义单一，不声称等同 LOLS 的混合或继承其定理。

[AggreVaTeD](https://proceedings.mlr.press/v70/sun17d.html) 把 cost-to-go oracle 用到可微策略更新，并在机器人控制、部分观测与依存分析上展示效果。它支持“利用训练时可以查询的未来任务损失”，不要求重新从随机 PPO 起步；但其近最优 oracle 假设与我们的有限 C7 续局不同。为降低小样本工程复杂度，本题先回归配对差，不预设 natural gradient、GRU 或 LSTM。

### 7.3 主动信息表示：S07、S08

[CAtNIPP](https://proceedings.mlr.press/v205/cao23b.html) 以 GP 增强图、注意力、LSTM 与 Pointer 选择下一节点，PPO 优化预算内信息收集；文中每预算为 30 实例×10 次试验，并在 TurtleBot3 打印灰度图实验验证。其预算 mask 保障到达终点，**不是把 10–16 个未知频道全部清除**。论文也承认动态归一化的信息奖励与原目标存在偏差，因此本题不用信息增益替代秒/源。

[OffRIPP](https://arxiv.org/abs/2409.16830) 把行为支持约束 Q 用到 IPP，在 2D 光强和 3D 果实识别、各 50 测试实例比较。表 I 的 expert 数据预算 10 下，行为策略 covariance trace=3.73，OffRIPP=3.96，BC=7.02，越小越好；它改善 BC 不等于超过强专家。其离线 PPO 对照不是正确 on-policy PPO 的普遍对照。Eq.4 不等号与 τ 端点文字有表面矛盾，本题不照抄。这也解释为何本次不再把旧候选支持 Q 当默认突破口。

### 7.4 风险：S04、S11

[SPIBB](https://proceedings.mlr.press/v97/laroche19a.html) 在不足支持的 state-action 上复制基线概率；有限折扣 MDP 的理论条件与深度伪计数实验分开。实验覆盖随机 MDP、随机格世界与连续 helicopter navigation；更实用的放松版并不拥有同样保证。我们的残差裕量只受其“有疑问时用基线”思想启发，不是实现 SPIBB。

[Safe RL via Shielding](https://arxiv.org/abs/1708.08611) 根据安全规格及环境抽象合成前置/后置屏障；本文关注 safety fragment，而“最终全部清除”还需要有限进展与预算的 liveness 责任。C7 几何完成层不能只用合法 mask 或有限失败罚分替代。本题独立兜底来自自己的物理证明，不来自该论文的实验。

### 7.5 扩展与暂不采用的路线

- S09 [RF active sensing 2026](https://arxiv.org/abs/2605.12569v1)：可看 recurrent 输入和 active sensing，但是单发射源、多天线 IQ、Sionna；其 current/goal 输入部署可得性未解决，PPO/DQN 配置不同。
- S10 [Multi-step Proximal Policy Improvement，2026-09-03](https://arxiv.org/abs/2609.03842)：明确自称未同行评审预印本；重定中心的近端 actor 更新仍依赖 critic 准确度，不解决缺反事实反馈。本文只读摘要、引言与目录，保持扩展层。
- S12 DyPNIPP、S13 RESeL：元数据可取得，本次尝试的 HTML 版本正文获取失败。可供后续动态适配/记忆检索，不当作本轮已深读证据。
- S14 TD-MPC2、S15 Flow Q-Learning：完整世界模型/连续生成动作会引入额外开销；当前有限操作阶段暂不采用。
- S16 C-IDS：需要精确定义 context、信息量和 regret；本题不把 Q 差/ensemble 分歧命名为真正的 information ratio。

这些论文没有共同任务、预算、传感器或评价指标，故不排跨论文 SOTA。近期方向确实增加了表达/优化选择，但本题当前优先缺口是“同状态不同动作的真实完整成本标签”和“能否转化为闭环改善”，不是拼装所有新模块。

## 8. 用户验收清单

- 接受只从 Q4 服务入口、最多 2 次干预开始，Q3 保留最新非 RL 最优。
- 接受先做不训练的 G0/G1，未证明有限动作有余量即停。
- 接受训练 fork 只在本地隔离评测端，所有候选和部署严格只看公开历史。
- 接受静态监督门控基线；如果它已足够，就不为“必须是 RL”而继续堆机制。
- 接受总预算与分层验证，最终测试/官方执行要在另一步冻结和授权后完成。

本稿认可的范围最多是“值得按门槛实施的研究计划”。在真实候选、训练、闭环与最终验证完成前，不能称它已突破 C7 或本轮最新最佳效果。
