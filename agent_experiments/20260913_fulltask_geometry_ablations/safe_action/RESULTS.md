# 安全行动域的Q3完整任务消融

日期：2026-09-13。本实验在冻结的1200个 `LOCAL-v1` Q3核心案例上，对B3执行同world单因素配对消融。两臂各实际执行1200局，共15550个源/臂，全部清除并正常退出。这是已暴露本地回归集，不是盲测或官方Windows成绩。

## 1. 唯一开关

两臂共用SHA256为 `e6a0666d644ceaa1d7ae69f19042b9ca022379f3e5a57d927e52bcf1a09360bd` 的B3。只覆写Q3运行时MRO中的 `_P3._LensSpatial.route_clear_point(center, radius, original)`：

- **完整 `C_clear(P)` 臂**：保留B3的 `lens_clear='route'`。当最小包围圆半径不超过20 m时，在
  \[
  \mathcal C_{\rm clear}(P)=\bigcap_{v\in V(P)}B(v,20)
  \]
  内结合当前位置和路线后继点选择落点。
- **MEC中心臂**：在同一已认证单次清除状态中，永返回最小包围圆中心。

`near`同址清除、未认证试清、自适应多圆分区的圆心及顺序、发现、测向、可行域更新、调度、失败恢复和退出逻辑都不变。由于落点会改变下一步状态，后续行为数可以分叉；这是单开关完整闭环消融的预期结果。

完整预登记见 `registration.json`。其中于任何策略执行前固定了输入路径与散列、开关、指标、seed簇bootstrap和退出门槛。

## 2. 完整任务结果

| 指标 | 完整 `C_clear(P)` | MEC中心 | 完整臂减少 |
|---|---:|---:|---:|
| 平均秒/源 | 229.196347 | 229.904617 | **0.708271** |
| 测向数 | 129739 | 129739 | 0 |
| 光学clear尝试数 | 22632 | 22555 | -77 |
| 失败clear数 | 7082 | 7005 | -77 |
| 移动距离/米 | 13006084.948 | 13061841.595 | **55756.647** |

完整安全行动域使平均时间下降 **0.708271秒/源（0.308072%）**。对“完整臂 − MEC中心臂”的配对差，按相同seed在12个场景中组成的100个簇做20000次bootstrap，95%区间为 **[-0.816170, -0.593080]秒/源**。预登记的完整任务时间门槛通过。改善小于建议中“0.5%上下”的量级，但配对区间已稳定低于零，因而可以表述为小而稳定的本地完整任务收益。

总移动距离减少55756.647米，平均每局减少46.464米（0.426867%）。光学试清和失败试清各多77次，说明减少路程是收益主因，后续状态分叉的少量失败成本抵消了一部分收益。按“先逐局除以该局源数，再对1200局取平均”分解完整臂减MEC臂的-0.708271秒/源：

- 移动：-0.715174秒/源；
- 测向：-0.005264秒/源；
- 换频：-0.001029秒/源；
- clear尝试：+0.013196秒/源。

四项合计与主指标差一致。两臂的测向总数相同，但不同源数的个案中测向数有少量互换，所以逐局归一后的贡献不严格为零。

## 3. 退步与适用边界

1200局中，完整臂1103局更快、1局相同、96局更慢。个案配对差中位数为-0.831242秒/源，5%和95%分位数分别为-2.028004和+0.497310秒/源。因此“平均稳定改善”不意味着逐局单调不劣。

12个场景中11个的平均时间改善；`origin_cluster`从156.264528增至156.837844秒/源，退步0.573316秒/源。最差个案 `LOCAL-v1-q3-exactly10_sources-5049` 退步21.436970秒/源。这些退步主要反映“为预测后继点选边界点”与实际后续调度/同址服务发生分叉，不是清除认证失效。正文可报整体完整任务收益，同时应保留聚簇场景退步这一限制。

完整臂是当前B3的路线目标启发式，并非对 `C_clear(P)` 上全局最优完整任务落点的证明。本结果也不外推到Q4、未暴露新样本或官方环境。

## 4. 认证、真值边界与复现

主运行记录了16611次已认证单圆落点。为避免只信任候选内的最大距离字段，又对注册的两臂做了1次确定性审计回放，保存每个P的全部顶点和实际clear记录：

- 2400个审计回放与主运行虚拟时间逐局完全一致；它们是重复确定性执行，不增加独立样本数。
- 16611个落点全部对应到真正发出的 `certified=True` clear动作；
- 全部落点覆盖其P的全部顶点，最大重算距离19.999999900013米；
- MEC臂全部落点与它的MEC中心一致。

策略对象只接收 `InterfaceOnly(enter, measure, clear, exit)`。两个候选包装不含案例ID、seed、源数、源坐标、半径或真实朝向；真值只在评测层用于构造环境和事后计算全清。冻结evaluation散列在执行前后均通过。完整臂的1200个虚拟时间与历史B3保存行逐案例完全相同，证明主臂的审计包装没有改变B3行为。

复现命令见 `COMMANDS.md`。主原始行为 `full_1200/rows.jsonl`，配对行为 `full_1200/pairs.jsonl`，顶点级审计为 `full_1200/execution_geometry_audit.jsonl`，汇总为 `full_1200/summary.json`，31项独立复核见 `VALIDATION.json`。首次顶点审计脚本未处理“某局零次安全行动域调用”而中止，已在 `audit_attempt_1_failure.json` 保留失败记录，修复后从空输出重跑并全部通过。
