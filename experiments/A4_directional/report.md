## 1. 题目结构、代价与信息边界

源位置在1800米圆域、数量10–16、频道互异且1–20。Q4兼有全向与定向源。定向可接收区是1000–1500米圆盘与过源闭半平面的交集；朝向和半径未知。测量误差有界±1度且同址固定，示向度保留两位小数。`clear`在20米内必成功，不受发射方向影响。

动作虚拟成本为：`measure` = 移动距离/5 + 换频道×1 + 5秒；`clear` = 移动距离/5 + 3 + 成功×2秒。只有停止位置有观测，移动途中不测量。每局评价量是本局总虚拟时间/实际清除数，再在完整场景内求算术均值；没有自造加权官方总分。现实20分钟和虚拟100小时另作完整性约束。

原版已具备保守示向度多边形、22个Q4发现站点、有限光学覆盖、16源数量上界及扫描完备退出。本路线原始瓶颈是：第二测点跨过发射半平面后失联，原恢复环可能产生长距离返回；即使已有较小位置集合，仍可能继续花费射频恢复成本。

在线代码只调用`enter/measure/clear/exit`。开发评测层使用自建源真值算清除比例和耗时，策略不读真值、case ID、场景名或回归缓存。未训练权重、未下载运行模型、未修改HTTP。四个标准库依赖为json/math/os/time。

### 2011.10474v2：Probabilistic Radio-Visual Active Sensing for Search and Tracking

作者：L. Varotto, A. Cenedese, A. Cavallaro；2020年，arXiv v2。[原文](https://arxiv.org/abs/2011.10474v2)。类别：状态建模/可见性与无检测似然/多模态粒子贝叶斯。

**实际读取**：正文PDF第1–3页；第5–6页数值实验、表I与结论；第4页只读部分定理，不声称完整校验全部证明。

**论文做了什么**：带无线电接收机和云台相机的UAV搜寻并跟踪发射目标；方向性相机和低精度RSSI互补。 用粒子滤波递归贝叶斯更新位置分布；公式15区分FoV内外、检测/未检测。未检测在FoV内的似然为1−检测概率，FoV外为1；RF与视觉似然相乘。控制平台位置和云台姿态。

**论文证据与边界**：作者Python合成环境150次、每次100迭代；表I给出RF+V 77%、RF 55%、V 26%、2RF 64%检测成功率。位置/云台固定消融39%和29%。这是移动目标检测比例，不是本题全清时间。 RF假设目标总在接收范围，使用可得RSSI、高斯噪声和移动目标模型；本题只给有界示向度，方向性在发射端，不能照搬似然数值。控制代价自己承认纯利用、不显式节能。

**本题启发**：有/无信号都更新位置、发射方向、接收半径联合假设；不能把无信号直接改成位置排除。RF与光学各有边界，应成本敏感切换。

**进入代码与否**：R1 / visibility_hypotheses, predicted_visibility, second_point, rescue_bearing：原创简化迁移：离散位置/方向与解析半径积分，仅排序，不复现论文运动粒子模型；R2–R3 / rescue_bearing, optical_points, optical_route：RF/光学互补启发；R2提前有限光学覆盖，R3由位置假设选择完整路线，均已完成开发与full；R4 / visibility_hypotheses, clear：失败clear只更新离散位置权重的自拟消融；full退步，最终未采用；R6 / rescue_bearing：用同一可见性估计门控自拟镜像点；小幅full改善但三个场景退步；R7 / expected_optical_time, rescue_bearing：近似RF/光学成本切换；full退步，最终未采用。

**本题实验是否支持**：R1 Q4较原版改善0.32064%，但5/12场景退步；R2、R3改善，R4、R7失败，R6仅小幅均值改善。支持本地排序/模态互补的用途，不证明论文似然在本题校准，也不把逐轮组合差异归因于单一论文。

### 2209.07660v1：Sequential Bayesian Optimization for Adaptive Informative Path Planning with Multimodal Sensing

作者：Joshua Ott, Edward Balaban, Mykel J. Kochenderfer；2022年，arXiv v1。[原文](https://arxiv.org/abs/2209.07660v1)。类别：决策规划/多模态动作成本/信念MDP与在线树搜索。

**论文做了什么**：未知环境中有不同成本/精度传感器，移动和检测共同消耗预算；仅规划移动不够。 GP表示环境信念；belief MDP奖励组合任务奖励与近似互信息（协方差迹下降），MCTS-DPW处理连续信念并剪除预算不可行动作。

**进入代码与否**：R1 / rescue_bearing：移动/检测成本除以预测可见概率的自拟近似排序；未复现MCTS；R2–R3 / rescue_bearing, optical_route：以任务成本选择光学搜索及两条完整路线；成本模型为自己的实现；R6 / rescue_bearing：以预测成本门控镜像一次恢复；自拟有限动作选择；R7 / expected_optical_time, rescue_bearing：显式RF/光学预计成本比较消融；full退步，不纳入R6；R8 / rescue_bearing：用移动/检测成本决定是否进入已可见点连线；凸性方案自己的推导，full退步。

**本题实验是否支持**：成本要与信息共同考虑的原则得到实现，但复杂成本近似R7和保证可见的R8均失败；不能声称更复杂规划必然更快。R2对照含snake端点变化，非单变量因果消融。

**进入代码与否**：未采用 / 无对应实现函数：未采用：原覆盖证书已可用，改站点需另证。

**本题实验是否支持**：未实现对应论文算法，因此没有本题实验支持；未采用理由见implementation与limitations。

## 3. 最终R6如何工作

维护两个层次的状态。保证层是每条示向度的±1.005001度半平面交集及保守接收半径外包，必须包含真源。规划层从多边形取算术顶点中心及向中心收缩25%的顶点样本；每个位置配36个等角方向与一种全向假设。全向先验0.5、方向先验合计0.5、接收半径在1000–1500米均匀，是自拟近似，并非官方给出的分布。

对位置s、方向n，正观测点决定可行半径下界；位于方向正侧的无信号点决定半径上界，背侧无信号不限制半径。有效区间长度乘方向先验产生权重。查询点q的可见概率由区间内满足距离条件的长度解析积分，再对有限位置/方向求和。无有效离散假设时退回0.5；这些近似永不裁掉保证层。

决策顺序：

1. 保留原第二测点的横向几何，在左右候选中用移动与600米尺度的失联惩罚排序。
2. 失联且多边形最小包围圆半径≤300米时，直接进入完整光学覆盖。
3. 否则评估失联点相对测向中心线的镜像；只在偏移≥5米、距原点≤3500米、未重复、预测成本优于线段中点时尝试一次。
4. 未恢复则朝旧可见点二分折返，最多两次；仍失败使用原救援环，环内按移动/检测成本除以预测可见概率排序。
5. 光学覆盖保留全部25米格点；小集合从最近格点出发，比较先去左端或右端两条完整路线的预计首次清除成本。预算到180000秒后用原snake并有限完成剩余任务。

R4的面积积分/clear失败离散样本排除、R7的成本模态切换、R8的凸包内恢复均被淘汰，未混入R6。R2同时包含更近snake端点这个基础改动，其开发对照不是字节相同R1，因此不能把全部R2增益归因于300米阈值。逐轮改进是组合策略的局部研发证据，未做全部因子组合的因果消融。

## 6. 可靠性与时间

保留原22个Q4覆盖点与扫描所有未排除频道的逻辑。每个目标位于一个边长<1000米的覆盖三角形内；过目标的任意闭半平面至少包含该三角形一个顶点，因此任意方向都可发现。退出依旧只依赖16源上界或全部几何覆盖。

真源始终属于保守多边形。25米网格方格中心到方格任意点≤25/√2<20米，因此保留全部相交格点就保证最终清除。R3的路线顺序没有删点，内部长度≤原snake两倍，超预算时退回原snake。R5的折返和R6镜像仅是有限恢复尝试，不承担完整性。

## 8. 结论的适用范围
