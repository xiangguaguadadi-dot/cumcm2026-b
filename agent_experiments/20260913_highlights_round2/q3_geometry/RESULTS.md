# Q3/Q4 服务几何补充验证结果

日期：2026-09-13。主 solver 与冻结 evaluation 均未修改。

## 建议纳入的新亮点：可认证开放路径与精确尾程

第三、四问在任一时刻都可能同时存在“尚未访问的搜索站”和“已经发现、等待定位清除的频道”。把两类任务统一成从机器人当前位置出发、终点自由的欧氏开放路径。C7 当前采用三个确定性初始序列，经 2-opt 和单点重插入后选择最短者；本实验进一步增加两个审计层：Held–Karp 动态规划给小规模状态的精确最优值，MST 给无需穷举的下界。

固定状态中，若启发式长度为 `H`，精确最优为 `OPT`，包含起点与全部任务点的 MST 长度为 `L`，则

`L <= OPT <= H`，所以 `H/L` 是启发式最优性比值 `H/OPT` 的可审计上界。

对 4 类合成几何各 120 个状态、任务数 5–12，共 480 个状态实际求解：

- 480/480 路线均恰好访问每个任务一次，480/480 不劣于最近邻。
- 461/480 达到 Held–Karp 精确最优；平均相对最优差为 0.0872%，P95 近似为 0。
- 相比最近邻平均少 397.504m。`H/L` 平均 1.1713、最大 1.4284。
- 不能只报平均：最坏状态 `annulus-075` 的启发式路径为 8579.623m，精确最优为 7723.442m，差 11.0855%。这说明局部搜索仍有可修正尾部。

预登记门槛“平均 gap <1%、P95 <5%、不劣于最近邻”全部通过。两簇状态 120/120 全部精确最优；圆环类包含最大离群值，说明环状边缘任务是更应关注的压力几何。

基于离群值再做的**事后候选**是：剩余任务数 `n<=10` 时切换到 Held–Karp 精确尾程，较大任务集继续用原启发式。在 360 个满足阈值的既有合成状态中，精确尾程修正 11 个状态，固定代理距离累计减少 1973.573m，平均每个合格状态减少 5.482m，单个状态最多减少 856.181m。600 次 batch=1 本机计时中，`n=10` 的 P50/P95/最大值为 8.485/11.891/13.041ms。

这个点适合写成“启发式快速全局调度 + 小规模精确尾程 + 在线最优性证书”。当前证据验证了算法机制和固定状态距离，尚未把精确尾程接入完整 solver，也没有测反复重规划的累计计算费或任务秒/源。因此不能把 1973.573m 直接换算成完整任务收益；本机延迟也不是官方 Windows 延迟。

## 交叉审计：失败 clear 的反馈剔除（不建议作为本轮独立主亮点）

失败 clear 推出真实源与尝试点距离严格大于 20m。对“可行多边形与 25m 格的交集”，若其全部顶点都落在同一个半径 `20-1e-6` 的失败圆盘内，因为交集与圆盘均为凸集，整个交集都可安全删除。仅凭格中心落入圆盘不能删除。

2,000 个合成多边形夹具共检查 256,000 个满足所有失败反馈的可行点，误删 0；86,639 个相交网格中保留 81,043 个，减少 5,596 个（6.458%），每夹具平均减少 2.798 个。该结果是合成集合检查。

另按 case_id 重算已有 `r2_one_round_exposed` 与 `r3_failure_cells_exposed` 的 2,400 个共同 Q4 暴露回归案例：两臂均 2400/2400 全清；平均从 457.721500 降到 457.664042 秒/源，配对差 −0.057458，按 200 个 `(suite, seed_cluster)` 簇做 10,000 次 bootstrap 的 95%区间为 [−0.113431, −0.013394]。逐例 505 更快、1620 相等、275 更慢，失败 clear 平均减少 0.3071 次。

相对收益只有 0.012553%，且这些行是既有暴露回归数据的重算，没有新增闭环运行。协调侧也在独立复核同一几何，因此本点保留为交叉验证，不作为本支新亮点占位。

## 证据边界

- 合成任务点与合成多边形不是真实题目 world，不能据此声称秒/源改善。
- Held–Karp 最优只针对当前冻结的欧氏代理点；新观测会改变区域、服务入口和后继位置。
- 失败反馈的 2,400 对是已暴露本地回归，不是新留出、盲测或官方 Windows 成绩。
- 路径下界不包含测量 5s、换频道 1s、clear 固定费、定位迭代及失败动作，不能当完整任务时间下界。
