# Q4 安全覆盖与自适应路径：有界机制调研

截至 2026-09-12。本次不是领域全景或 SOTA 排行；范围只覆盖能解释当前 Q4 瓶颈的连续覆盖、成本耦合、在线规划与定位代理。共 6 篇去重论文：5 篇核心机制段落阅读，1 篇扩展摘要。并未声称把 5 篇全文逐字读完。检索词、访问版本与原始页面保存在 `literature/`；程序下载不等于人工深读。

## 结论与分类树

```
Q4：全部清除约束下的时间最小化
├─ 连续覆盖证明
│  └─ 有限见证 + 未覆盖区域修补 → A Closer Cut (2022)
├─ 覆盖与路径费用联合选择
│  ├─ 二值覆盖 + 边际路径费用 → Guaranteed Estimation Uncertainty (2026)
│  └─ 圆邻域中的访问位置 → Circle-Neighborhood TSP (2020，摘要扩展)
├─ 在线知识更新后的重规划
│  └─ 树复用 + 重新计算信息收益 → IA-TIGRIS (2025/2026)
├─ 定位决策分布
│  └─ 最大熵重加权 + D-optimal → MaxEnt Bearing Placement (2026)
└─ 条件边际收益的理论边界
   └─ Adaptive Submodularity (2010/2011，修订 v5)
```

可迁移的共同原则是：先分清哪些量只是规划代理、哪些约束保证任务完成；再把选点和路程联动。它们均没有证明当前 C7 的收益或本轮候选的优越性。

## 核心机制阅读

### 连续覆盖：A Closer Cut

[原文](https://arxiv.org/abs/2211.05891)。阅读引言、4.1–4.4、5.1–5.3。作者用有限见证的 close-enough TSP 给下界，再修补未覆盖区域获得完整可行上界；鲁棒余量/单元尺寸连接有限见证与连续覆盖。实验为割草巡回问题，非本题的定向接收。原文分支定界/二阶锥求解并未在本轮复现。

本地影响：允许网格筛选，但把连续证书作为进入策略实验的前置条件。7+13 构型三版各通过 260,640 点抽样，仍未获连续证书，因此没有拿来跑任务。不能把证书未获写成已发现真实覆盖漏洞。

### 成本耦合：Informative Path Planning with Guaranteed Estimation Uncertainty

[原文 v3](https://arxiv.org/abs/2602.05198)、[RSS 官方收录](https://roboticsconference.org/program/papers/183/)。阅读 III–VII，重点 V 的二值覆盖构造、GCB 边际覆盖/路由费用、VII 限制。单位置 GP 方差阈值转成覆盖集合，GreedyCover 先选点再 TSP，GCBCover 联合考虑路由增量；实验包含地形数据和 ASV/AUV。

本地影响：R2 用真实已观测源的几何位置与未来覆盖站的连接成本选相位。没有使用其 GP，也不继承近似比。原文保证只覆盖有限评估点、依赖核正确性；不能据此声称本题的连续源域或定向天线得到保证。

### 在线规划：IA-TIGRIS

[原文 v3](https://arxiv.org/abs/2502.15961)、[作者项目页](https://ia-tigris.github.io/)。阅读 III、IV、V 中树复用、belief embedding、消融和时域讨论。它重新利用可行搜索树，但随新观测重算收益；不是缓存旧路线后永远不更新。其信息收益用乐观观测近似，实验目标是预算内熵下降，而非全部目标成功清除。

本地影响：R3/R4 仅在尚未访问任何非原点站时更新整体几何；不改已有覆盖证据。两者局部代理有道理，但整局开发/quick 均不如已保留 R2，因此不晋级。不是 IA-TIGRIS 复现，也没有把连续航迹上的传感当成本题免费 measure。

### 位置决策分布：MaxEnt Bearing Placement

[原文](https://arxiv.org/abs/2605.11116)。阅读 II、IV、V。先在给定分布精度约束下最小化 KL，得到向当前均值集中的指数重加权，再按加权 Fisher 信息做 D-optimal 放置。64 个源/传感器配置、两噪声级别、20 次种子实验；存在少传感器场景退步。作者实验为多传感器 Gaussian 8°/15° 噪声、RMSE 目标。

本地边界：本题单运动机、±1° 同址固定误差、移动/清除耗时目标，不能直接替换概率模型或借用其收益。R2 的区域中心是排序代理，保守多边形不因此收缩。本轮未实施最大熵粒子重加权。

### 理论边界：Adaptive Submodularity

[原文 v5](https://arxiv.org/abs/1003.3967)。阅读条件边际收益与定义 1–3、自认证定义、修订定理 13 及历史说明。适应次模性要求条件期望边际收益随已知信息增多而不升，并依赖概率分布；它不是所有信息搜集问题的默认性质。

本地边界：本题移动费用依赖当前路径、16 源发现后取消站点产生耦合，尚未证明适应次模，故不套贪心近似比。v5 明确修正定理 13 的旧证明，使用更强假设和平方对数界；未沿用旧版本结论。
