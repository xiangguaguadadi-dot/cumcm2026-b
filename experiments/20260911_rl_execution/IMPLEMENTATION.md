# RL共同实现与验证

本轮承接已审阅的两条学习路线，执行入口是[授权与预算协议](EXECUTION_PROTOCOL.md)。第一、二问、主目录求解器、固定环境和原C7均保留。当前结构是C7提供宏动作候选，BC/PPO/Q选择任务顺序，共同执行器负责真实接口调用和独立接管。它不是完整Graph Transformer、GRU、IDS或世界模型。

## 数据和动作边界

策略只取得enter、measure、clear、exit返回的公开观测。共同snapshot有16维全局特征、20×12维频道特征、K×16维候选特征及合法mask；K≤64。完整历史状态、候选payload、路线后继、服务状态、版本和动作身份另存，便于核对和重放。候选按payload散列排序，教师动作不固定排在首位。

真实源数N、源位置、类型、seed、场景编号、成绩均不进入神经网络。教师索引用于BC标签及Q的教师锚点，不是网络特征。执行结束后，协调层独立读取真实清除数与正常退出状态，在轨迹外层生成终局标签。

候选集借助C7构造：教师候选保留C7优化后的路线后继，其他任务采用其登记的后继规则。因此学习器的成绩应归因于“C7候选与学习调度的组合”，不能宣传成网络从零发现了完整策略。观测特征是压缩表示，未证明满足Markov条件。

共同网络为64维隐藏层、候选对频道的轻量注意力，31,938个参数；其中候选评分路径23,617个参数，状态价值头8,321个参数。PPO使用评分和价值头；Q的价值头不参与损失。Q另保存target与冻结BC支持模型，其成本包含在Q运行耗时与进程峰值中，未单独消融测量增量。

## 完成与费用

学习端点限制在[-4000,4000]²，每次真实请求前后检查虚拟时间、请求数、现实剩余时间与接管条件。至多10,000次学习measure/clear，连续32个无有效进展的调度决策触发不可逆接管。学习时间门槛300,000秒，单请求上界2,300秒，独立兜底预留53,000秒。

兜底使用49个发现站和每源至多304个光学清除格点，继续当前物理位置与清除账本，不再次enter。理想题设响应下的虚拟时间构造及数值检查见[core报告](core/REPORT.md)。现实网络、服务端响应和计算没有确定上界，因此该构造不等于官方现实期限内无条件完成保证。

完整费用满足：

`prefix_time_s + Σ decision.delta_time_s + tail_time_s = total_time_s`。

接管尾段和失败都保留。训练目标采用T0=1000、γ=1、每步奖励`−ΔT/(1000N)`，实际失败仅在终端额外记一次−100；真实终端不bootstrap。N只在结束后归一一次，有限失败罚分不冒充“零失败优先”的数学等价形式。

预算按实际四种业务调用计数，包含enter/exit；measure/clear可由分项账本单独计算。每个新增训练局进入前预留15,846次调用，覆盖10,000次学习请求、5,844次兜底请求和enter/exit，避免在局中舍弃尾费用。PPO与Q使用相同每初始化的局数与调用上限，实际消耗分别报告。

## 算法与固定配置

- BC：同一批512局纯C7示范；三份独立网络初始化；每份8遍、每批8完整局、每批1次Adam更新。保存对应BC作为独立对照和PPO/Q共同起点。
- PPO：每批8个当前策略完整episode，Monte Carlo回报，clip=0.2，每批4轮、Adam学习率3e−4、梯度上限0.5。actor按episode等权求决策和，critic按episode内决策均值；保存采样时完整snapshot、mask、动作身份、旧logprob/value与策略版本。
- Q：冻结BC相对支持门槛κ=0.1并保留合法教师；先在共享示范上4遍MC拟合，再每个新增episode从全部共享示范与本初始化已完成训练局中均匀无放回抽取8整局作一次TD更新。online网络在保存的下一候选中选择，target评价同一动作，τ=0.01。
- Q前128训练局采用80%教师、20%其他合法候选，每局至多8次偏离；之后90%部署规则、10%其他合法候选。部署关闭探索。

Q的经验特征范围只由共享示范与该初始化新执行的训练观测累计扩展，不读取选择集。global[6]/[14]是真实已用/剩余时间，保留网络输入和硬期限守卫，但只检查有限性与物理[0,1]范围，不以训练耗时极值作几何越界判断。此v2规则在G2训练前固定；它避免机器负载直接触发经验范围回退，仍不消除网络对真实时钟的依赖。

## 记录、恢复与可复核范围

完整轨迹保存为gzip，保留压缩文件和原始JSON的SHA256。训练只在需要时载入均匀抽取的完整episode，避免把全部快照常驻内存。每次重放核验文件散列。

执行前先写持久化started预留；若执行中断且没有完整轨迹，不能在未知费用下自动重复执行。同一完整gzip已保存而指标账本缺失时，可从文件恢复账本，不再运行环境。费用验证失败也必须先保存完整结果与实际调用数，随后停止训练。

训练更新通过pending标记、含last_update的原子checkpoint及可恢复日志衔接。恢复会核对计划、示范账本和运行代码；PPO恢复当前模型与采样RNG，Q另恢复重放及探索RNG。未提交的中断计算单独标记未知时间/步数，不冒称零成本。实际有无这类中断以最终证据审计为准。

完整原始轨迹保留在本地，Git保存代码、具体配方、依赖、权重、每局指标与原始文件散列索引。公开复核不能仅凭散列读取被排除的大文件；完整逐动作重放需要本地原始轨迹。相同环境种子可以重建本地物理场景，但真实时钟仍是网络输入，重新采样不保证逐bit复现同一动作序列。
