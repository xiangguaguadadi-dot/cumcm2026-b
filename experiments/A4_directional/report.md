# A4 定向发射与信号可见性独立研究实验

研究截止2026-09-11。当前完成第五轮，延长阶段仍有提升；最终结果将在后续候选结束后补齐。所有结果为LOCAL-v1本地回归，不是官方Windows模拟器结果。

当前最佳R5：Q3 306.30043421816345、Q4 534.7506409587284秒/源，分别1200/1200全清正常退出。Q3逐局保持原版；Q4均值改善6.32927%，十二个Q4场景均优于原版。R1曾有5个场景退步，保留在迭代记录中。所有正负开发与回归结果均保留。

研究主张：半径、发射方向未知时，无信号可更新动作排序用的概率假设，但不应直接裁掉真实位置可行域。R1对位置/方向作有限数值积分，对1000–1500米半径作解析区间积分，预测第二观测点与救援点可见概率。只改变既有动作顺序，原有±1.005001度保守多边形、22个Q4覆盖点、16源上界停止和有限光学覆盖保留。

调研10篇一手来源：4篇核心正文阅读、6篇扩展，其中2篇仅元数据/摘要。逐篇作者、版本、原文、实际阅读范围、机制、实验证据、局限、采用状态与对应函数在[literature.json](literature.json)；检索词及失败记录也在该文件。重点包含无线电/视觉贝叶斯无检测似然、多模态成本规划、有界误差集合成员、主动测向几何。没有声称下载即深读，也没有把文献实验数字迁移成本题成绩。
