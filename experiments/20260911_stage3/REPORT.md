# 第三阶段研究汇总：已收束

本阶段完成两条优化路线，共10轮探索，其中9轮完成完整回归，1轮在开发阶段止步。最终采用第三问R2 R4与第四问R3 R5。按用户最新要求停止追加校验，直接交付已有结果；本阶段没有生成或运行新的最终留出样本。

**最终效果**

以下均来自同一套4800个已暴露案例，第三、四问各2400局、30970个源。指标为每局“总虚拟耗时÷清除数”的算术均值，单位秒/源。

|题目|本阶段起点S0|最终方案|平均节省|降幅|完整清除|
|---|---:|---:|---:|---:|---:|
|第三问|238.426471|235.876946|2.549525|1.0693%|2400/2400局，30970/30970源|
|第四问|524.827144|473.897493|50.929651|9.7041%|2400/2400局，30970/30970源|

统一入口已经在全部4800案例上实际运行，任务结果与两个最终组件一致。平均改善并不意味着每局都更快：第三问1624局更快、776局更慢；第四问2174局更快、226局更慢。第三问原点聚集场景仍有约0.55%退步，相关负例全部保留。

**收敛过程与主要发现**

第三问路线的主要变化是把可靠的观测约束接入协同搜索：用正观测、无信号与清除失败收紧可行区域；按后续完成任务的预计费用决定是否补测；最后在全部可行源位置共同允许的20米清除区域内选择更合适的停点。最后一轮尝试多位置假说和决策区图代理，最终开发均值为父法231.260930、多位置231.366210、图代理232.454323秒/源，两个新变体都未胜父法，因此保留R4。三版开发与两次修复记录完整保存，没有把它们包装成新的独立验证。

第四问的主要收益来自协同补测、实际发现16个互异频道后取消额外发现，以及联合安排覆盖站与待清源的访问顺序。最后两轮进一步优化清除落点，边际收益已经较小：R3为474.329486、R4为474.207931、R5为473.897493秒/源。R3简化版同样保留，便于后续在复杂度与小幅收益之间选择。

两条路线都出现了末轮收益缩小、开发排序反转或更复杂代理未胜父法，已按用户允许近收敛收尾的要求停止研究。这是当前探索范围内的收束，不宣称全局最优。
