# 论文事实口径审计 v1

> 审计对象：`docs/论文正文初稿_v3.md`。目标不是润色，而是检查“正文是否比仓库证据说得更强”。结论分为：✅ 可直接写；⚠️ 需限定；⛔ 不应写。

## 1. 总结

当前正文主线总体与仓库事实一致，未发现需要推翻的核心模型。最需要继续守住的边界有四个：

1. Q1 必须保留“空集/无界/有界”判断，不能用1800m任务圆域替代问题一本身的有界性判断；
2. Q2 的 `(600,±300)` 只能写“合法默认候选/可实施示例”，不能写成全局最优；
3. Q3/Q4 的中心、未来观测、概率可见性等只能写成排序代理，不能写成可靠定位证书；
4. 4800案例全部属于已暴露研发回归，不能写成独立泛化测试或官方成绩。

# 2. Q1 审计

## 2.1 半平面交

✅ 可直接写：每次 ±1° 示向对应两个闭半平面；所有观测求交后必须先区分空集、无界和有界。

来源：`docs/第一问_定稿.md`。

⚠️ 注意：问题一的定位区域首先是“纯观测半平面交”。1800m目标圆域是第三、四问在线任务先验，不能用它把问题一的无界区域自动截成有界。

## 2.2 40m等边三角形反例

✅ 可直接写：

- 三个检测点：`(-1100,0)`、`(590,-550√3)`、`(570,570√3)`；
- 示向度：`1°、121°、241°`；
- ±1°扇区交恰为边长40m等边三角形；
- 直径40m；
- 最小包围圆半径 `40/√3≈23.094m>20m`。

因此“以定位区域直径为直径的圆必覆盖”是错误命题。

## 2.3 直径充分条件

✅ 可直接写：若只使用直径给出保证20m清除的充分条件，可以要求

\[
D\le20\sqrt3\approx34.641\text{m}.
\]

仓库定稿已经确认该结论。

# 3. Q2 审计

## 3.1 精确稳保接收域

✅ 可直接写：

\[
C_{sig}=\bigcap_{g\in\Omega_1}B(g,\max\{1000,\|g-S_1\|\}).
\]

关键解释必须保留：1000m是**接收半径下界**，不是源到首测点距离下界。

## 3.2 保守候选区域

✅ 可直接写：局部坐标中

\[
x^2+y^2\le10^6,
\]

\[
x^2+y^2\le2000(x\cos\delta-|y|\sin\delta)
\]

构成精确稳保接收域的安全子区域。

✅ 可直接写：它等价于三个半径1000m闭圆盘的交。

## 3.3 默认点

⚠️ `(600,300)` 与 `(600,-300)` 只能写：

- 合法；
- 首段移动约670.82m；
- 移动约134.16s；
- 适合作为默认可实施候选。

⛔ 不能写“最优第二检测点”。仓库明确说明距离未知时不能盲目追求90°，也不能断言固定点对所有场景最优。

## 3.4 一阶定位尺度

✅ 可写但必须带限定词“局部一阶近似/量级解释”：

\[
D_{lin}\approx
\frac{2\delta\sqrt{r_1^2+r_2^2+2r_1r_2|\cos\beta|}}
{|\sin\beta|}.
\]

⛔ 不应把该式写成真实半平面交区域的精确直径公式。

# 5. Q4 审计

## 5.1 no_signal语义变化

✅ 必须突出：定向源中 `no_signal` 可能来自发射背面，不能直接推出距离超过1000m。

这是Q3→Q4最重要的模型升级触发点。

## 5.2 21站覆盖

✅ 可写“连续几何认证的21站覆盖”。

✅ 可写局部凸包证明思路：区域内真实源属于若干1000m共同近邻站的凸包；任意经过源的闭发射半平面必包含至少一个凸组合顶点。

⚠️ 正文不必展开四叉树/整数证书实现细节；这属于支撑材料。

## 5.3 条件发现路线

✅ 可写：只改变访问排序；真实站点取消仍仅在发现16个真实互异频道后执行。

⛔ 不应写“根据概率提前删除覆盖站”。

## 5.4 重测费用门控

✅ 可写：未知频道扫描完整保留；已知频道额外测量按预计后续动作收益与真实5–6s检测费比较。

⚠️ “预计收益”是规划近似，不是严格最优判据。

## 5.5 one-round服务

✅ 可直接作为Stage4主要结构创新之一：单次全局调度只执行原定位循环的一轮，频道迭代状态持久保存，再返回全局任务选择。

✅ 可用耗时分解证明其主要减少移动。

## 5.6 no_signal凸楔

✅ 仓库已有独立凸性推导，可直接写：

\[
s=q+a(q-p_1)+b(q-p_2),\quad a,b\ge0
\]

会推出

\[
q\in\operatorname{conv}\{s,p_1,p_2\}\subseteq C
\]

与q无信号矛盾。

⚠️ 必须强调：最终使用的是保守外包，可能把部分禁区放回来；正确性来自“不删真源”，不是最大化区域缩小。
