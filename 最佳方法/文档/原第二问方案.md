# 第二问结果：稳保信号的斜向前进策略

依据B题问题2及附录1、2。适用全向源；已有一次正常示向度观测。若首次返回near，直接尝试光学清除，不必再选第二测点。

令首次检测点为S₁，示向度为θ。将S₁平移到局部原点、θ旋转到局部x轴。令δ=1°，Ω₁为与首次观测、目标圆域相容的全部源位置。源距首测点可以小于1000米；1000米是接收半径的下界，不是源距离的下界。

## 精确的稳保接收候选区域

C_sig = ∩_{g∈Ω₁} B(g, max{1000, ‖g−S₁‖})。

理由：对每个可行源g，其未知接收半径R至少为1000米；首次接收成功又要求R≥‖g−S₁‖。要求第二点在所有这些最小可能接收圆内，就能保证所有与首测相容的场景都仍有信号。B为闭圆盘；near也算接收到信号。

## 简单可实施的保守候选区域

将Ω₁放宽为0至1500米、角度±δ的完整扇区。局部第二点(x,y)满足：

x²+y² ≤ 1000000，
x²+y² ≤ 2000(x cosδ − |y| sinδ)。

等价于三个半径1000米圆盘的交集，圆心分别为(0,0)、(1000cosδ,1000sinδ)、(1000cosδ,-1000sinδ)。它是稳保接收的安全子区域；考虑目标圆域或源距大于5米等附加信息，可能扩大区域。

证明：写源位置g=t(cosα,sinα)，|α|≤δ。t≤1000时，距离平方关于t为凸函数，检查t=0和1000足够。t≥1000时，稳保要求‖(x,y)−g‖²≤t²，即x²+y²≤2t(xcosα+ysinα)；上述条件使右侧投影非负，最严位置为t=1000及角带端点。两个不等式由此给出全扇区保证。

例如(600,300)及(600,-300)都合法。首段移动670.82米，移动耗时134.16秒，原频道再次检测另耗5秒。纯横移没有保证：源在(1000,0)、接收半径1000米时，任意(0,y)、y≠0都会失去信号。

转换回全局：S₂=S₁+x(cosθ,sinθ)+y(-sinθ,cosθ)。实现给出局部检查和两个默认候选，见q2_candidates.py。

## 定位效果与移动成本

选择“向前并适度横移”，避免两条观测方向近乎平行或反向共线。在安全候选区域内，给定移动预算后可枚举候选点，比较最坏可行源位置下的定位区域半径，并优先选择顺接后续搜索路线的一侧。

局部一阶近似：若两测距为r₁、r₂，交会角为β，δ使用弧度，定位直径量级为

D_lin ≈ 2δ√(r₁²+r₂²+2r₁r₂|cosβ|) / |sinβ|。

此式用来解释交会几何，不是精确直径或全局最优证明；最终区域仍用半平面交计算。距离未知时不能盲目追求90度交会角，也不能断言(600,±300)是所有场景的最优点。

工程上示向度只输出两位小数；保守实现将角带放宽至±1.005001°。本文件理论按题设±1°，q2_candidates.py默认采用工程角带。第四问的定向源可能离开有效半平面，不直接沿用全向稳保结论。
