# 第六阶段研究路径增量

本目录只追加 `S6_` 节点，不改旧图、旧节点、旧统计。先读原 [exploration_index.json](../exploration_index.json)、[第四阶段增量](../stage4_increment/index.json)和[旧 RL 执行增量](../rl_increment/index.json)，再读本目录生成的 `index.json`。仅当前 index 列出的节点有效，重新生成不删除遗留节点文件。

生成器在 A1 最终账本和协调者组合验证未就绪时拒绝正式发布；`combined.py` 的初始构建登记不构成已执行证据，最终身份须由 `CURRENT_BEST.json` 绑定。

## 读取与计数约定

- A1/A2 的实际代码父法与当时保留的晋级对照分别保存。A1 R8 的代码父法是 R6b，晋级对照是 R7；A2 R3–R5 也不把保留 R2 假称为整个代码父法。
- A1 R6 未执行稿、R6a 的失败执行、R6b 修复分别留节点，共用一个 R6 round key；修复不另造算法轮次。失败行不过滤成成功子集成绩。
- 五轮 A2 相位算法、三轮几何研究分别记录；网格通过不等于连续证书，未获证单元不等于真实漏洞，180 个20点布局反例不等于证明20点整体不可能。
- 单文件封装、最终 Q3/Q4 组合、原样等价检查与合成合同测试不算新的算法优化全测轮。RL 方案节点是授权前历史快照；后续 G0/G1 执行注册与状态另立节点，不把计划预算或旧训练变成新训练成绩。
- `counts_as_completed_4800_round` 只针对完整保存4800案例且身份匹配、全部正常全清的算法轮次；它与 `retained` 不同，完整回归但未晋级的负结果仍保留。
- `retained` 表示当时晋级并用于下一轮的历史状态，不等于最后只选这一份；`selected_final_per_task` 与 `current_lane_best` 才标识最终分题选择。
- quick 是 full 的已暴露子集；各节点 scopes 可能复用同一批行，不得跨节点相加当独立世界或实际执行数。各路线账本的执行成本单独保存，不与重叠 scope 数重复求和。
- A1/A2 累计请求来自批次保存行，称为“已记录本地请求”；`rows.requests` 不计参数预校验或状态拒绝尝试，缺少逐请求尝试日志时不能宣称累计全尝试精确无漏。RL 新流水记录尝试，最终轨迹复跑的全尝试核对也只覆盖它实际复跑的24例。
- RL 实时状态注明记录时刻，可能仍在执行，不代表 G0/G1 已完成。状态计数与独立复算调用流水分开；流水缺失记为 `null`，未决调用不伪记为零或失败，后续进度不能从旧快照推断。
- RL 注册和计费状态在正式生成时复制到本目录 `snapshots/`；流水如存在只归档独立计数必需字段，保留原路径、原字节散列、采集时间及投影规则，不把接口载荷全部复制进图。节点绑定固定副本，后续RL执行不会使本版过时快照自动变成当前状态，也不会使其归档散列失效；后续结果另立增量。
- 正式组合须同时满足最终父法/SHA、4800保存行审计、4800任务字段等价和24案例/48次请求轨迹复跑的状态与输入散列；24案例轨迹不能冒称4800全轨迹一致。

## 复建与校验

只读试构建（不写 index、不执行策略）：

```bash
python3.12 -S -B experiments/R1_atlas/breakthrough_increment/build_increment.py
```

待 A1 所有轮次终结、最终组合与主审全部完成后正式生成：

```bash
python3.12 -S -B experiments/R1_atlas/breakthrough_increment/build_increment.py --write
python3.12 -S -B experiments/R1_atlas/breakthrough_increment/validate_increment.py
python3.12 -S -B -m unittest discover -s experiments/R1_atlas/breakthrough_increment -p 'test_increment.py' -v
```

生成器仅使用标准库、只读现有文件与重新计算保存行，不导入求解器/环境、不运行策略、不联网、不修改旧图或原始结果。缺失或仍在变化的最终证据会阻止正式生成。`manifest.json` 为所有实际读取的来源保留仓库相对路径、SHA256、角色与可点击相对链接，也绑定生成 index 和各节点的完整文件散列；源文件更新或生成节点被修改后不再通过校验，须重新生成。

数据验证用于检查案例 ID、分母、T/清除数公式、失败状态、每题/场景均值与候选身份。它不证明求解器安全性、几何证书正确性或论文迁移有效性；这些依赖各节点链接的专门证明和审查。所有结果都是本地已暴露回归，无新增密封或官方测试。
