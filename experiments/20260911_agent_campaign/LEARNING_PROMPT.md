# 两位学习方向 Agent 共用研究提示词

研究方向：从数据驱动的策略学习与自动发现角度，探索怎样在保持第三、四问完整清除可靠性的前提下，减少平均定位清除时间。两位 Agent 使用完全相同的这份研究任务，各自独立探索；不预设算法类别、模型规模、训练方式、策略结构或具体技术路线，也不互相借用对方方案。

先深入理解题目、现有求解器的观测与行为、动作时间代价、覆盖和终止保证。随后进行非常深入且覆盖不同竞争方法族的文献调研，实际阅读原始论文或作者正式资料，分析适用性和局限。文献对方案是软约束：有更好的原创思路可以采用，不为了对齐某篇论文勉强实现。允许上网、下载适合的公开模型、权重、数据和代码，但必须记录来源、版本和复现方式。

基于调研和独立思考形成具体方案，再编写代码、运行实验、分析结果并迭代；每人先至多三轮候选；如果第二轮到第三轮仍持续提升，可继续第四、第五轮及之后的迭代，延长后连续两轮没有刷新完整评测验证的当前最佳即结束。每轮均须完整执行共同 PROTOCOL.md 中的规则检查、quick/full、当前最佳记录与提交要求。训练或自动搜索的内层多次评估要用自行生成、与固定 v1 不重合的训练/开发数据，公开其预算和尝试数；禁止把隐藏的回归集调参包装成一轮。推理期只读标准接口观测，不读真实源、案例ID、评测标签或基准缓存。训练期若用真值或特权教师须明确说明，并验证与部署观测的边界。

每次跑完必须记录当前最佳；有经过完整评测的提升就立即提交代码与对应结果。没有提升也要保留候选、失败信息和原因。若两题收益存在取舍，分别报告，不能虚构加权综合分数。保留可靠性和全部清除保证，任何覆盖/终止逻辑变化须给出论证。不要再派子 Agent。

不论效果好坏，交付完整中文实验报告，并保存 experiments/<自己的ID>/{report.md,literature.json,plan.md,iteration_log.md,best.json} 和实现、训练/复现实验脚本、模型依赖散列、全部评测结果。报告必须逐篇写出实际调研的文献（题名、作者、年份、原文URL）、实际阅读范围、核心机制、对本题的启发、是否进入代码及对应轮次/函数、未采用理由；形成“文献→启发→实现→实验”的可追溯关系。不要只列参考文献，不把下载全文当成已阅读，也不把摘要阅读当成全文深读。自己的设计与原论文方法、论文结论与本题实测必须分清。

请持续向主 Agent 汇报实质性发现、每轮实验结果和最终代码/报告路径。只修改并推送自己的专属 worktree/分支，保持与另一位学习 Agent 的独立性。当前资源不足时，可以调整到能真实完成、可复现的方案，并如实解释取舍。
