# 六边形光学覆盖的连续保证

令 R=19.999 米，a=√3 R。局部坐标中的站点为

c(i,j)=(1.5 R i, a(j+(i mod 2)/2)), i,j∈Z。

其相邻站点距离均为a。垂直平分线给出6个法向 n_k=(cos(π/6+kπ/3),sin(π/6+kπ/3))、支持常数a/2的Voronoi六边形。相邻支持线交点距中心R；六边形为这些顶点凸包，故整格位于半径R的闭圆盘。所有这些闭格覆盖整个平面，边界重合不影响覆盖。

1. 当前保守凸定位域P变换到局部坐标。对每个格，仅保留P与6个闭半平面之交非空的凸片。
2. 某格可能含P点时，其中心两个坐标距离P的坐标区间不超过R。代码按这个必要条件计算i范围，并为交错j额外放宽一格，所以有限枚举不会遗漏任何相交格。
3. 清除失败位点f证明实际源不在B(f,20)内。只有凸片全部顶点到某个f距离≤20-10^-6，才删除该格；圆盘的凸性保证整片已排除。不能只检查格中心、样本或平均距离。
4. 任意仍可能的实际源s属于一个枚举格，该格不能被上述失败认证排除；于是s到保留格中心≤R<20。最终按完整有限列表逐一执行clear必在源仍存在时成功。

原点平移、格轴旋转、不同完整列表之间的概率排序都保留上述证明。portfolio只在四份已各自完整覆盖的列表之间选择，不按概率删除单元。RF发现仍使用父法认证21点及既有可证明统一旋转，退出证书不变。

浮点实现保留0.001米半径余量，原有clip容差和失败盘余量更小。`check_geometry.py`另做6顶点半径计算、48个细长/旋转矩形×3相位角度、26908个未排除样点的诊断。样点不是连续证明；连续保证来自无限格剖分、有限范围完整枚举和凸片顶点认证。

# 连续定向可见概率的适用边界

对一个位置假说s，正观测要求R大于所有已见点距离，并要求定向朝向θ满足相应半圆角区间；一个负观测若落在此朝向半平面中则要求R小于该负点距离。所有正负点的θ±π/2端点将[0,2π]划分成有限区间，其间每条正负不等式真假恒定。

对每区间积分其角宽乘以可接受半径长度，并对待测点可见的角区间与半径范围再取交，即可精确积分该离散位置假说下“均匀R、均匀θ、全向概率1/2”的模型。该模型是排序假设，非官方概率分布；位置积分仍是有限近似。加入area quadrature与失败点样本排除也只影响排序。代码不修改P、发现覆盖证书或失败清除认证。

# 最小接收半径定向负信息

新增源排除域由q朝两正观测点p1,p2的正锥，以及越过p1p2直线且远离q的严格半平面组成。域内每个s可写为s=q+k(b−q)，其中k>1、b是p1p2线段上的凸组合。重排即q−s=λ1(p1−s)+λ2(p2−s)，λ1,λ2≥0且λ1+λ2>1。任何能收到两正点的真实发射朝向n都满足n·(pi−s)≥0，从而n·(q−s)≥0。如果再有||q−s||<1000，则按公开的R≥1000，q必收到信号，与实际no_signal矛盾。

p1p2直线上的点不按此推理排除；代码远侧半平面内缩10^-4米。两锥边也留同量余量。圆界用R=999.99米内接16/32边形，或者仅当原poly全部顶点到q≤999.99时用圆的凸性免去圆裁剪。每一凸内排除域的补集按各外半平面与原poly相交后取并，再取凸包；因此留下的域是安全外包。只有原顶点能被排除时才计算碎片，该加速不会漏掉有用的凸包收紧。

`check_minradius.py`包含24000个合法定向观测不误排检查、6000个纯超距无信号检查、1482个随机排除点的独立非负锥系数验证，以及明确的直线边界反例保护。它们只是实现诊断，正确性依赖上述推导。

# 从A1迁移的有限光学操作符

只迁移凸条划分、MEC服务圆和固定点序列的期望首次命中DP。Q4保留原试点center，失败信息采用Q4的_e2_failed_clear；没有导入“no_signal排除1000米圆”这条仅全向成立的假设。

将整个原凸域按直径轴划成2–6个闭凸条，finite_r6将候选扩展至7/8条及145米原域MEC门槛，finite_r7进一步试验9/10条及185米门槛。每条MEC半径≤20−10^-5。服务点位于MEC中心周围半径20−r−10^-5的小盘，随后再次逐顶点检查全条到服务点≤20−10^-6。各条覆盖原域，因此完整服务序列覆盖所有位置。若前N−1次clear失败，则实际源必在最后一个盘，最后一次可标certified；前面仍按普通试探clear执行。实际动作始终经过父类时限守卫，入口先检查虚拟兜底。

对固定服务点q_i和仅用于规划的假说集合，DP状态为(已访问集合mask,最后站last)。一条边的期望成本为尚未命中的假说比例×(距离/5+3)，最终统一加必成功清除的2秒。完整union必须覆盖全部规划假说，否则返回无限代理成本并不采用计划；这项守卫不承担连续证明。DP对固定点集精确，对移动服务点选择、有限位置分布和动作门控依然只是代理。

finite_r8的服务点修正仍限制在各凸条的认证小盘内，并再次逐顶点检查；重复DP后保留的是一份完整覆盖序列，故连续保证不依赖顺序或代理成本。finite_r9只增加用于排序的积分点，覆盖证明不变。

从finite_r3_guarded起，整个序列以`_protected_clear_plan=True`包围，try/finally还原调用前状态。该标记要求融合的试探clear组件不得改写任何计划点；各点自身的certified参数仍只在最后一站为True。若融合组件忽略标记，则完整覆盖论证的前提被破坏，因此父协调者另做融合测试。本分支独立运行的r3和guarded版本在2400个相同v1案例的完整动作指标相等。
