# 对新增负信号几何的独立审阅

这是本轮 A2 提出的独立方向，尚不能在实测前称为提速。论证只使用题面的接收半平面、最小接收半径及真实正/负观测。

设候选源位置为 s，两个已经收到信号的检测点为 p1、p2，无信号点为 q。对定向源，存在固定单位法向量 n，使所有收到信号的位置 p 满足 n·(p-s)≥0。若

`q-s = λ1(p1-s) + λ2(p2-s), λ1≥0, λ2≥0`

则 n·(q-s)≥0。再若 ||q-s||≤1000，由最小接收半径保证 q 应收到信号，与观测矛盾。因此这些 s 可以排除。全向源也满足这个排除结论。

原有凸可见区域主要处理 λ1+λ2≤1，即 q 位于 s,p1,p2 的凸包；新的分支处理 λ1+λ2>1，需要另用最小接收半径保证 q 的距离。

## 可实现的半平面表述

令 u=p1-q、v=p2-q，且 u,v 不共线。将 s 写成 `s=q+αu+βv`。对从 q 指向 p1,p2 的楔，α≥0、β≥0；直线 p1p2 远离 q 的严格半平面是 α+β>1。令 γ=α+β-1，则

`λ1=α/γ, λ2=β/γ`

确实满足上式，且系数非负。与 B(q,1000) 的交集就是可以保守排除的一块区域。实际实现应使用具有严格余量的半平面与半径小于 1000 的内接多边形，避免数值误删。对原可行多边形扣除该凸区域后，剩余碎片的凸包是允许扩大不确定性的保守表示。

## 必须保留的边界反例

`s=(100,0), p1=(100,100), p2=(100,-100), q=(800,0)`。

发射法向 n=(-1,0) 时，p1,p2 位于包含的发射边界，而 q 位于无信号一侧。这里 α+β=1，虽然 q 与 s 的距离只有 700 米，仍不得排除 s。因此“远离 q 一侧”必须严格排除直线边界，不能用含等号的半平面直接删除。

## 本题性能边界

这个规则增强的是可靠可行域约束，不是概率排序。它不依赖源分布、天线方向先验、误差的独立性或高斯假设。但若扣除的区域完全位于原多边形内部，重新取凸包可能把它补回，最后没有任何收缩；计算增加也可能抵消规划效果。必须看完整真实动作的配对实测，不从新定理推出算法提速。
