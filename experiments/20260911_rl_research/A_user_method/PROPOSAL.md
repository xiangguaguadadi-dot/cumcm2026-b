# A方案：对 CBG-PPO 的核实与修订提案

研究截止：2026-09-11。当前版本：R2，已逐项回应 C-R1，待最终复评。本轮只检索、阅读、资料整理与纸面推导；没有实现新策略、训练、运行环境或更改 C7。

## 1. 结论与用户待审阅事项

建议保留附件的“几何 belief + 候选动作调度 + 独立完成证书”主线，**不把 Graph Transformer + GRU + PPO 的完整组合预先定为最终模型**。用户批准执行后，先验证 C7 的可接续候选接口，再在同一最小阶段比较 BC、轻量 masked PPO 与 B 的受行为支持约束 Q；只有图关系或历史模块带来可重复增益才升级。A 个人优先检验 PPO，但这属于实验信息价值与工程顺序判断，不表示已经选出算法冠军。C7 继续作为现有默认与首要强对照。

关键依据有三点。第一，CAtNIPP 已经明确采用 Transformer、LSTM、Pointer actor/critic 和 PPO，因此这些模块的组合本身不是新颖性证明。第二，RF 的 80.1%/76.3% 数字真实，但信息协议、任务、训练配置与本题不同。第三，退出 mask 只能禁止早退；要说“确保全清”，还要有可以从实际状态接管、预算足够且必有限结束的完整兜底。下面给出这一责任的具体构造，现实网络时限仍明确有条件。

本轮筛选纳入 29 篇去重记录：9 篇阅读关键正文，20 篇扩展记录；不声称任何核心文献均逐页全文精读。扩展中 IRIS 目前只有准确出版元数据。主要窗口 2024–2026，另保留 CAtNIPP 与两篇安全/masking 奠基材料。实际阅读范围、原文位置、代码访问和失败检索见 literature.json、search_log.json。没有同协议证据证明本题 PPO、DQN 或模型规划谁是 SOTA。

## 3. 可观测状态：可靠集合与概率近似分层

### 3.1 事实层和接口状态

共享 StateStore 只从被接受的 enter/measure/clear/exit 事件更新：实际位置 p、当前测向频道 c_cur、虚拟时刻、现实余额、已成功清除频道、所有实际观测、C7 的服务进度、覆盖待办及候选执行上下文。accepted=false 不更新状态，不把其 virtual_time_s=0 当真实时刻。重试保持 request_id 和 payload；未确认的动作不能被再次当新动作执行。

各频道唯一且静态，允许逐频道存集合，但不是声称 20 个频道概率独立：总源数 10–16 给出跨频道存在性关联，共享误差场也可能相关。证明层可以忽略这种关联以得到保守外近似；概率层若忽略，则明确是建模近似。

### 3.2 可靠假设集合

对尚未 clear success 的频道，定义活源参数 ξ=(G,R,τ,φ)，G∈D（半径1800圆域）、R∈[1000,1500]，τ 为 omni/directional，φ 对 omni 无意义。分别保存：

- `F_c,alive(H)`：假设当前确有活源时，与实际历史 H 相容的联合参数集合；
- `a_c,absent(H)`：当前无源的分支是否仍与历史相容。未清除前，direction 或 near 是排除 absent 的实际活源证据；成功清除后直接转入 cleared 状态，不再用“从未有源”的 absent 解释旧正观测。

整体假设为 `F_c(H)=F_c,alive(H) ∪ ({absent} if a_c,absent else ∅)`。实现时可保留隐式约束列表和经过证明的外近似，而非把位置、半径、方向几个 marginal 的任意笛卡尔积冒称精确 joint belief。

- direction：除可见性与 5<d≤R 外，保留 `|wrap(angle(G−S)−θ̂)|≤1.005001°`。其中1°来自有界误差，0.005°覆盖两位小数舍入，再加0.000001°数值外包；实现仍需确认裁剪/外近似运算本身保守，不能仅靠加小数就声称所有浮点步骤严格。
- near：d≤5 且有信号，直接请求同址 clear；不能赋一个假示向度。
- no_signal：对活源分支施加 `d>R OR (directional AND 位于发射半平面之外)`；absent 分支保持可行，除非已有正观测排除了它。不能在 Q4 无条件删除 S 周围1000米圆。
- clear 成功：唯一频道记 cleared；clear 失败：活源分支增加 d>20，与 RF 发射方向无关，absent 分支仍相容。

同址误差固定。模型不得把在同一 (S,c) 的重复 direction 当独立样本；预测未来观测也必须条件于固定误差场。近邻误差相关性未知，不能默认 IID Gaussian 再赋予确定性保证。

`certified-empty` 要求以可靠外集合证明 `F_c,alive=∅`，同时 absent 仍可行且没有矛盾的实际活源证据；全域鲁棒覆盖的实际无信号记录是这一排除活源的另一条证书路径。**整个 F_c=∅ 意味着观测、模型或数值处理不一致，不是空频道证明。** 此时撤销不可靠裁剪、恢复更保守外包并重核已接受事件；在问题未解释前只能保守标 unknown 或进入兜底，不能据此 exit。全局还核对题设10–16源的计数不变量。有限粒子消失、log-area 小、网络概率小都不构成证书。

`localized` 仅是调度标签。确定性清除证书应验证整个可靠位置集合包含于一个半径≤20的圆；“直径≤40”本身不够。

### 3.3 给网络的近似层

概率 particles/网格可用于 P_detect、P_clear、预计信息价值，但必须有明确生成模型与权重更新。粒子耗尽应重采样/回退可靠外集合，不能把频道标空。若尚无可信概率模型，第一版不使用名为 mutual information 的量，只用“几何缩小代理”或解析最坏情况指标。

面积、中心、包围半径、已观测方向分布、最近失败/无进展计数、coverage待办比例等摘要不是完整 Markov 状态：两段不同 no_signal 历史可能有相同面积/中心而有不同未来观测分布。完整历史加正确模型原则上可形成充分belief；压缩摘要只能视为部分可观测输入。先给网络显式历史统计，再由同预算 `无GRU/有GRU` 对照判断是否值得记忆。

## 4. 候选动作与 C7 接续契约

附件 `(q,c,o)` 对单次 HTTP 操作足够，但对现有 C7 宏动作不够。C7 的 measure 包装可能 near→clear，localize 可能补测、恢复与跨频道共享；spatial_next_task 还会写 route_successor，影响后续落点。因此候选必须是不可变执行 payload，冻结 option 类型、目标、successor、相关参数与期望入口状态。枚举候选不能留下“最后一次查询”的副作用。

用户批准后最先做的接口验收应是：**同一包装器始终选 C7 自身候选时，核对原请求轨迹、状态转移和费用**。当前共同 wrapper 的学习坐标 box 是 [−4000,4000]²，但并未验证其包含 C7 全部恢复动作。若 box、预算守卫、候选截断改变 C7 的轨迹，G0 必须报告差异，修正合同或将其明确作为受约束 C7-wrapper；不能直接宣称恒选等价。原 C7 始终保留独立对照，wrapper 的差异不能归因于学习选择器。不能新建 C7.run 接管，因为它再次 enter 并重置待办。候选选择、执行和事件入账分离；在 primitive request 边界检查预算与中断。状态改变后重建候选，不能执行已过时 payload。

第一阶段候选包含：C7 原下一服务选项、未完成的覆盖站/频道任务、已发现源的少量几何测量点、认证或启发式 clear 选项、必须可用的 fallback 下一步。`SEARCH/LOCALIZE` 是上层标签，最终执行仍是合法 measure/clear 请求。保留 C7 的启发式 clear：题设允许失败并付3秒，不能把所有 CLEAR 都 mask 成“必成功”后声称完整复用 C7。是否更严格禁止试探应作为额外策略约束单独比较。

初始 K_max=64 是待审阅的工程起点，候选不足则 padding+mask；不能为凑 K 随机丢掉 C7/fallback 选项。后续只有候选截断经分析发现重要动作被遗漏才扩大到128。每条 PPO rollout 保存当时完整候选特征、身份、mask、旧logprob和实际执行payload。动作序号只在该状态有效；更新时不能拿重新生成的候选算 ratio。

同址重复 mask 也需修订：无信息重复通常可不生成；但 `(S,c)曾测过` 不意味着该 measure 在当前位置不可用，因为移动/频道切换嵌在它里面，没有免费 move。严格无效动作、被证明支配的冗余动作、为 C7/兜底保留的交通动作要区分。原始 request_id 重试不属于新的策略动作，fallback 可重用历史观测或合法复测；不能被学习层去重规则阻断。

## 5. 网络与算法：先检验调度价值

建议的阶段是：

1. **BC 与轻量 masked PPO**：相同候选，按候选共享 MLP 编码，pooling 编码频道集合，点积/MLP打分候选。与固定排序拼接 MLP 对照分开；前者不是原封不动 SB3 的固定特征MLP。
2. **Graph PPO**：机器人、频道、候选三类 token，候选→所属频道边、机器人→候选代价边，必要时以 relation bias 表示空间共享。先1–2层、d=64，后续容量只在训练/选择集决定。
3. **Graph Recurrent PPO**：只有摘要别名或长时历史失真仍造成可重复失败/低效时加入128维GRU；序列采样需保留边界、hidden reset、padding及必要 burn-in。不能只打乱transition minibatch。

“百万参数”不是训练速度证据。普通 dense padded attention 可避免第一版引入 PyG；是否使用 MPS 取决于运算支持、CPU/GPU搬运和batch规模。MaskablePPO 与 RecurrentPPO 是分开实现；SB3-Contrib 当前官方文档对 MaskablePPO 明确标 recurrent policies 不支持，因此动态pointer+mask+GRU需自定义策略/rollout，而非拼两个类就完成。首轮 memoryless 对照可降低该风险。[官方MaskablePPO说明](https://sb3-contrib.readthedocs.io/en/master/modules/ppo_mask.html)

保留竞争方案是“相同候选与belief下的 Double-DQN/保守离线Q”以及有实际预测模型的有限深度规划。若加 IDS，必须定义 latent target、posterior、regret 对照和 information gain；`(max Q−Q(a))²/(IG+ε)` 加 ensemble 方差只能称启发式代理，除非证明与论文定义一致。C-IDS 已给出 policy-gradient 形式，说明 IDS 不是 DQN 的专属。这里只引用其机制；B 对已读证明中 Lemma 3.6 / Eq.19 与跨 episode 的 context 条件提出尚待核实的疑问。本项目未完成该理论的独立核验，既不引用其 regret 保证到本题，也不宣称已经证伪整篇理论。[C-IDS §2–4](https://arxiv.org/html/2602.03939v1)

## 6. 时间目标、宏动作与 shaping

严格按接受请求的实际状态转移记账：

`measure: ΔT=||q−p||/5 + 1[c≠c_cur] + 5`；
`clear: ΔT=||q−p||/5 + 3 + 2·1[success]`，且 c_cur 不变。

宏动作奖励使用其所有 primitive 请求的 ΔT 之和；预估 T_a 只是输入特征。原附加公式不能把 detection/optical/clear 当自由计费开关。

主评价遵循冻结协议：完整性、正常退出、异常/限时先检查；所有失败行保留。若同一场景任何候选失败，不给该场景耗时提升排名。全部合格后比较每局 `T_i/N_i` 的算术均值，分别报告 Q3/Q4；不按成功子集 `E[T|success]` 选冠军。

### 6.1 固定首版训练目标与可观测边界

首版固定 `T0=1000 s`，γ=1，优化完整 episode 目标

`J = E[−T_i/(T0 N_i) − 100·I_i(failure)]`。

每个宏动作的成本奖励为其全部已接受 primitive 的 `−ΣΔT/(T0 N_i)`；真实失败终端另加一次无量纲 −100（等价每源额外100000秒的训练成本）。这是与 B 共用的**待批准训练配置**。它与成功局的平均每源时间目标对齐，失败罚分用于避免廉价早停；任何有限罚分都不等于词典序“先零失败再比时间”，稀有失败仍可能在期望损失中被收益抵消，必须另外执行零失败门槛。全部失败保留，失败时 N_i 仍取训练真 N，绝不除以已经清除的 k。

N_i 只由训练器在 episode 结束后写入标签元数据，用于回报计算；actor、候选生成、StateStore、GRU 输入和 previous reward 都不读取它，也不读取 seed、场景ID、真实位置/类型/误差场、critic 特权 embedding 或训练器的最终真值成功标签。实际 clear success 是合法接口返回，可正常进入 StateStore/actor；它与离线 validator 的真值完整性标签必须区分。首版 critic 只读取与 actor 相同的可观测摘要 z，不引入特权 critic。原始 `−ΔT/T0` 如用于诊断对照，只能标为 E[T] 的不同目标，不以选择集结果改写两者数学等价性。

### 6.2 完整 episode 的 MC PPO 更新

首版不用 GAE、λ-return、shaping 或人工短 rollout 的 bootstrap。采集完整 episode，令 D_i 是该 episode 中**学习选择器实际抽样**的决策位置集合。对 t∈D_i，用该决策之后直到真实终端的全部已接受请求计算

`G_it = −Σ_{u≥t} ΔT_iu/(T0 N_i) − 100·I_i(failure)`，
`A_it = stop_gradient(G_it − V(z_it))`。

C7/fallback/重试的后续实际费用均计入 G_it。强制接管后的 fallback 请求没有学习抽样概率，不额外制造 logprob 或 actor 梯度项；RL→fallback 只是控制器切换，不能提前截断回报。若整局未发生学习选择，D_i=∅，它可用于费用/可靠性记录及 critic 数据，actor 求和为空。

保存每个采样时刻的候选快照 C_it、mask m_it、选择 a_it 和旧 logprob。定义

`ρ_it(θ)=π_θ(a_it|z_it,C_it,m_it) / π_old(a_it|z_it,C_it,m_it)`，
`L_actor(θ)=(1/B) Σ_i Σ_{t∈D_i} min[ρ_it A_it, clip(ρ_it,1−ε,1+ε) A_it]`。

按 episode 等权、episode 内对实际学习决策求和，首版 ε=0.2。不把每条 episode 的 actor 项再除以自身长度 L_i。若实现将同一整批所有决策除以总 transition 数，仅是该批统一尺度；不得将按长短 episode 重采样或各除 L_i 混同此式。完整 episode minibatch 均匀抽取，microbatch 累积保持该权重。首版不作 advantage 均值/方差白化，固定 T0 缩放，entropy 系数0；Adam 初始学习率3e−4，每批最多4轮 clipped 更新，梯度范数上限0.5。这些是可在读取选择结果前修改并登记的工程初值，不是文献导出的最佳超参数。

critic 拟合同一 MC 标签，可用 `L_V=(1/B)Σ_i [1/max(1,|D_i|)]Σ_{t∈D_i}(V(z_it)−G_it)²`，与 actor 分开优化，且不通过优势反传。critic 的逐局回归缩放不改变上面的 actor 权重定义。完整回报和 score-function 给出原目标的策略梯度方向；PPO clipping、多轮更新及函数逼近仍是近似，不能从回报等式推导 PPO 单调改进或收敛保证。

### 6.3 真终端与采样中断

- 成功 terminal：可靠完成条件成立、正常 exit 已被接受，并由离线 validator 判定真正全清；不 bootstrap。
- 失败 terminal：真实虚拟或现实 deadline、不可恢复协议/运行错误，或离线 validator 确認早退/漏源；完整记录实际成本并加一次 −100，不 bootstrap。因 deadline 剩余未完的任务不能冒称时间限制的可继续 bootstrap。
- 人工采样截断：世界和执行状态仍可连续恢复的批采样边界，不是真 terminal。首版保存现场、继续同一局直至真终端后再入 actor batch，既不强行清零末端价值，也不使用未定义的 bootstrap；无法恢复导致实际终止则按运行失败记录。

第一版不加 shaping。后续如采用，势函数 Φ 必须是有界、可观测、无量纲的量，所有真正终端（成功及失败）设 Φ=0，γ=1 下 `F_k=β(Φ(z_{k+1})−Φ(z_k))` 的完整 episode 和为 `−βΦ(z_0)`。这只是对固定初始状态的望远镜恒等式；人工截断不是终端，不能清零势。连续时间折扣 γ_k=exp(−ρΔT_k) 会改变成本早晚的权重，也不能仍称等价真实总时间。log-area、方向 marginal 熵与覆盖比例可以是有界代理，但不冒称 joint MI。

## 7. 证书、有限进展与双时限

### 7.1 退出证书

只有各频道均 cleared/certified-empty 且10–16源计数不变量一致，或已收到16个不同频道 clear success，才允许 exit。Q3 最小接收半径1000的圆盘覆盖加实际全部no_signal可证明空。Q4 用方向无关覆盖构造；一两个no_signal绝不能排空。学习策略不能修改证书。

### 7.2 不依赖 C7 内部收敛的保守兜底（纸面构造）

该构造用于证明责任和最坏情况，并非将当前 C7 常规路线改成49站。

1. 取 V=`{-1800,-1200,-600,0,600,1200,1800}²`，49个顶点，按蛇形走；每站测所有尚未clear/可靠排空的频道。D中的任意G属于某600边长网格方格，到其四顶点均≤600√2<1000。由于 G 在四顶点凸包内，任意过 G 的闭半平面至少包含一个顶点，因此任意定向方向至少一顶点能接收（near也算发现）。所以某频道全程49站均no_signal，就可证明没有活源。
2. 收到 near，直接同址 clear。收到 direction，以S为原点、测得θ̂为正向建立正交局部坐标(α,β)。活源有 α∈[0,1500]、`|β|≤1500 sin1.005001°<26.32`。
3. 清除点取 α=0,20,…,1500，β∈{−30,−10,10,30}，共304点蛇扫。上述矩形任一点距某格点≤√(10²+10²)<20，因此只要响应符合题设，至多304次clear必成功，方向背面也可clear。失败不错误删证据；成功后回被打断覆盖站继续未处理频道。
4. 返回站的移动由下一次合法measure/clear请求承担，不能新建免费move。不再次enter。学习阶段 StateStore 中已成功清除频道可以跳过；其余历史可保守忽略并重扫，避免依赖不可靠粒子或C7内部状态接管。

统一的条件合同设进入fallback时 p∈[−4000,4000]²。网格蛇形长48×600；进入首角距离≤5800√2。每源光学蛇扫与返回站的额外路径可用

`L_clear ≤ 30 + 76×60 + 75×20 + √(1500²+30²) < 7591 m`

界定。最多980次measure、16×304次clear；所有measure都保守按6秒，clear按304×3+2。因此

`B_V ≤ (5800√2+28800)/5 + 980×6 + 16×(7591/5+304×3+2) < 52196 s < 53000 s`。共同预留取53000秒。

这是题设理想响应下的**纸面虚拟时间上界**，不是实测性能，也不是已实现形式验证。退化边界、坐标旋转/舍入与数值覆盖仍是获批后验收事项。本构造光学点每个坐标分量保守小于4000，但 fallback 仍使用独立的合法动作规则，不能受学习去重或候选截断误挡。上述条件并未验证所有 C7 恢复动作也位于该 box 内；原 C7 与新 wrapper 的合同及差异须在 G0 分列。

### 7.3 调度强制接管与现实边界

共同合同把学习阶段允许请求落点限制在 [−4000,4000]²；当前位置也在该 box 时，任意下一 primitive 的移动距离≤8000√2。故 `measure ≤8000√2/5+6<2300 s`，`clear成功 ≤8000√2/5+5<2300 s`，失败 clear 更少。这个2300秒只适用于明确的合法 primitive 和该位置域；不能拿它给未验证的 C7 无界循环或超域恢复动作作上界。

在发出每个新 primitive **之前**检查预算，接受后再次检查。共同学习虚拟阈值 `B_RL=300000 s`，另设≤10000个已接受学习 primitive、连续32个学习决策无有效进展的接管阈值；有效进展只由首次有效观测、可靠集合严格缩小、实际覆盖义务减少或 clear success 定义，不由网络自报。首次达到任一阈值后不可逆切换 fallback。宏动作可在 primitive 边界中断，不能预检一次后无界执行内部循环。最后一个跨阈值 primitive 最多超调2300，因此 `T_total <300000+2300+53000=355300<360000 s`，保留4700秒以上算术余量；独立前置检查仍要求 `T_used+B_next+53000+ε_V≤360000`，拟定 ε_V=1000秒的额外虚拟裕量。如果合同入口不满足位置/剩余预算条件，不能声称这一界已成立。

现实 deadline 使用同一保守时钟下的 `D_real=min(t_enter+1200 s, D_25min_window)`，其中后者是实际官方25分钟窗口的截止，而非在接管时重新计25分钟。现实最坏请求数为5844个 measure/clear 加1次 exit。定义 fallback 现实储备 `B_real=5845 L_max+C_max+R_retry`，分别计单次已建立的通信确定上界、全程本地计算确定上界及有界重试费用。学习请求发出前检查 `t_now+C_next,max+L_next,max+B_real+ε_R≤D_real`；不满足时立即尝试接管，并核对剩余余额是否仍足够。未知延迟已耗尽储备时不能凭这次接管追认保证。

历史最大值/P99只是观测统计，不是数学确定上界；无界网络延迟下不能保证1200秒完成。若 enter 初始余额已不足，或这些确定上界/重试条件没有建立，则现实期限内完成的条件保证不成立。仍可实施保守进展与记录实际结果，但不能写“保证永不漏源”。当前没有验证官方网络上界。

## 9. 论文贡献的可守范围

可作为待验证研究问题的是：在相同几何候选与完整性约束下，学习跨频道的长期调度是否超过 C7；联合方向/存在性约束与显式候选关系是否提供增益；带有限剩余预算的完成守卫是否能与学习调度相容。它们尚未成为已成立贡献。

已存在的 attention+LSTM+Pointer+PPO、belief-guided RL、BC后RL、信息探索与硬规划混合，不能逐项宣称首创。若未来要投稿，需要针对准确任务、完成证书、信息协议和约束的进一步 novelty 检索。IRIS全文仍缺，不能把缺失来源作为新颖性的正证据。
