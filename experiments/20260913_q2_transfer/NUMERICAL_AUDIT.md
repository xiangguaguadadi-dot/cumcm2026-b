# B路线数值方法与共同评测的独立交叉复核

本复核只读B候选、注册记录和公开轨迹，并执行公开几何计算。没有调用 `Solver.run`、`LocalEnv` 或任何环境接口，没有修改候选、规则、案例或既有评测结果。

## 总体结论

未发现B1/B2/B3读取隐藏状态、改写可靠后验或削弱完整光学覆盖/无信号恢复链的行为。共同runner与独立行审计的案例配对、每局时间分母和full行复用逻辑没有发现影响本轮结果的漏洞。

扩角带方法可为**保留多边形与未来测向角带相交后的包围半径**提供连续读数覆盖上界；它不是所有隐藏物理状态的精确后验计算，也不能仅凭两个上界的大小关系声称实际最坏精度一定改善。75个公开选点记录已补充显式点对下界，支持更强的数值比较，但仍限定于上述多边形角带目标，并使用普通浮点计算。

## 1. 候选差异与信息边界

三份候选均完整嵌入相同父法源码，父法SHA256为：

`0bda4f711b9e9716739af8aedf456cb1eeefb47d8ba3ed230ca682c8450a96ea`。

AST提取后的实际差异与注册一致：

- B1的增量与当前 `B_improved/mechanism.py` 完全一致。
- B2相对B1只有一个排序表达式改变：`(rad[0], cost, q)` 改为 `(cost, rad[0], q)`。候选点、上界计算、成本门控和Q4可见性门控相同。
- B3相对B2只增加父点实际前进/侧移分量的 `0.8、1、1.25` 局部组合；去重后至多增加8个新点。它没有改变上界函数、成本系数或保护逻辑。

新增逻辑只使用 `polygons`、已有示向度、无信号位置、当前机器人位置和虚拟时间，以及父法公开观测驱动的规划采样/可见性函数。没有文件读取、案例ID、真源坐标、真实源类型、真实发射方向或缓存成绩进入决策。

新增类只覆盖初始化、候选生成、规划费用计算和 `second_point`。`measure`、`clear`、`run`、`cover_polygon`、`rescue_bearing`、`scan_station`、可靠多边形更新、有限光学覆盖均继承未变父法。局部 `_wedge` 调用返回新多边形，用于规划；没有向 `self.polygons` 写入预测结果。

## 2. 连续未来读数上界的条件

对应 `B_improved/mechanism.py` 第24–52行。对任一读数区间 `[a,b]`，设中点为m，将第二角带半宽从δ扩为 `δ+(b−a)/2`。区间内任意读数z的原角带都包含于这个扩大角带，因此其与当前poly的交集也被包含。扩大交集的包围圆半径便是这一读数区间的上界。

实现保留全部区间，每次分裂上界最大的区间，最后取所有剩余区间上界的最大值。提前停止或32次分裂上限影响紧度，不破坏区间覆盖。若扩大角带将达到或超过180°开角，函数回退整poly的包围半径，避免用两个前向半平面错误表达宽角区域。

保留多边形为凸外包区域时，顶点方位区间可覆盖可行源方位；若方位绕回使区间过宽，同样退回整poly，因此不会因该分支漏掉读数。读数半宽使用工程误差界 `±1.005001°`。

父法包围圆最后会重检所有顶点，故它是一个保守覆盖计算；本复核不把其浮点结果当成区间算术认证。模型也未在此规划函数中排除第二点5 m近场或加入第二次1500 m接收边界，这些省略使上界更宽，不会破坏对真实保留后验的覆盖，但会影响“lower”的解释。

## 3. 两个上界的比较不能直接保证真实精度不变差

候选实际门控为 `new_upper ≤ parent_upper`。这只保证所计算的上界指标不增加，不自动推出两点的真实最坏包围半径具有相同排序；父点上界可能更松。

源码变量 `lower=max(radius(midpoint_wedge))` 在理想精确MEC和所定义的角带模型下，可作为读数扫描目标的下界。但父法函数返回的是经覆盖重检的浮点包围半径。若未经独立最小性和舍入方向验证，不能仅凭变量名将它升级为严格下界证书；它也不是包含近场、接收距离、方向和全部非凸排除约束的物理状态下界。

因此，报告应采用“连续覆盖上界作为规划指标”“上界不增加门控”等措辞，不应笼统声称所有选点均获得严格的实际精度支配保证。

## 4. 75个选点已用显式点对替换MEC下界断言

原诊断为B1/B3各24个既有公开案例，共75次实际执行的改变点位动作：B1为24次，B3为51次。此次不重跑环境，而是使用 `public_trace` 重建每次决策前的可靠poly：Q3按公开示向度、物理切线、无信号和失败清除圆盘的父法外包规则更新；Q4在这些单观测决策前沿用首测角带和范围约束，未引入未知方向真值。

随后复算父点区间细分，在已访问的中点角带交集中寻找两个顶点g、h。任何包围圆都满足：

`radius ≥ ‖g−h‖/2`。

该下界不依赖父法MEC算法是否达到了最小值。每个点对均重新核对属于重建poly、落在同一个父点第二角带内；每条记录也核对到公开轨迹中的实际第二测量动作。

结果：

| 检查项 | 结果 |
|---|---:|
| 重建并核对的实际改变点位动作 | 75 |
| `new_upper < parent_pair_distance/2` | 75/75 |
| 最小分离间隔 | 1.216499983 m |
| 最大分离间隔 | 108.037294337 m |
| 重建上下界与原日志的最大差 | 1.65×10⁻¹² m |
| 原父MEC“lower”与点对距离/2的最大差 | 1.14×10⁻¹³ m |

新增的 [显式点对记录](A_transfer/B_geometry_pair_witnesses.json) 保存每次完整prior poly、父/新点、见证读数、点对、半径下界、执行索引及间隔；[重建脚本](A_transfer/cross_check_B_geometry.py)只做公开轨迹与几何运算。

几何计算调用B1模块中B1/B3完全相同的纯几何函数；AST提取已核对 `_wedge`、`_radius`、`_future_radius_bound` 源码完全一致。JSON使用 `geometry_evaluator_sha256` 标识几何计算模块，另以 `variant_sources` 分别记录B1/B3候选源码、对应公开诊断及共享几何函数的SHA256，不把75次动作归到单个候选散列下。

这75次的分离明显大于显示出的浮点差异，支持“在保留poly加角带这个规划目标上，有显式点对支持的精度改善数值诊断”。**它仍不是隐藏物理状态全集的严格保证，也不是区间算术证书。**没有进一步把点对同时认证为满足全部真实接收半径、定向可见性、非凸历史排除和官方未舍入误差的两个物理场景。亦未将这75次外推为所有回归动作或未来案例。

## 5. Q4近场费用预测存在明确的乐观近似

`_b_expected_future` 第84–85行在假定源距候选点不超过5 m时直接加5秒，并跳过后面的定向可见性计算。但对定向源，接收点即使很近，位于发射后半平面仍可返回 `no_signal`，而不会自动触发near后的光学清除。

这属于规划费用近似，可能低估该假设分支的后续费用；不能称为保守费用保证。它没有改写实际测量反馈或恢复链，因此不构成全清保护被削弱，也不推翻已经实际执行的闭环统计。为保持已冻结候选可追溯，本复核没有修改该分支。

九个poly内位置样本、三个等权误差情形和定向可见性概率均是规划假设，不是题目给出的真实概率分布。Q4的 `predicted_visibility` 门控只能表述为预测可见性不降低，不能表述为第二次必定可接收。

## 6. 共同runner、配对和复用复核

`evaluate_transfer.py` 按冻结fusion_r5的原始4800行建立父法索引，核对候选/父法/案例的唯一ID集合、mode/group/源数及每局 `总虚拟时间/实际清除数` 分母。只有全部比较行全清并正常退出且无错误时才计算有效比较；按题目、既有批次和场景分别汇总，没有将成功子集当成全体结果。

复用full要求候选SHA相同、共同注册SHA相同、来源为2400例full，并检查复用ID恰为既有v1子集。补跑只针对未复用ID，执行前登记复用文件散列。收束时B1/B2/B3的exposed记录均已完成，且均为“4800行 = 2400个相同候选full行 + 2400个实际补跑行”；公共最终行审计核对了三个版本的复用散列及逐行一致性。

`audit_campaign.py` 进一步逐行比较最终结果与 `executed_rows.jsonl`，要求复用ID与新执行ID互斥、并集等于结果ID集合，且复用行内容与来源完全相同；实际请求数只从新执行行统计。它调用另一份配对计算重算均值和分母，并核对源码/父法/runner/注册散列。未发现本次使用的输入和路径存在重复计数、错配父法或把复用行计成新执行的问题。

源码AST扫描明确只是结构检查；此次结论同时基于对B增量和共同评测实现的人工阅读。复核不涉及官方模拟器的真实性，也不将已暴露回归提升为新盲测。
