# 新亮点候选：把失败清除转化为20米圆盘排除信息

## 结论

一次 `clear(q,c)` 返回失败，按题设可严格推出该频道真实源 `g_c` 满足 `||g_c-q||>20`。因此失败动作不只是付出3秒成本，还得到一个圆盘外约束。当前B3将可靠位置多边形与圆盘外部相交；由于剩余区域可能非凸，实现取其凸包作为保守外包，再用于后续测点与清除规划。

该机制的**安全性和实际信息量得到验证**，但本轮完整闭环没有分辨出独立提速：开启相对关闭仅减少0.004498秒/源，种子簇95%区间跨0。

## 构造几何压力

在2,000个确定随机种子的凸多边形夹具中，真实源均位于原多边形内，失败点与真源距离严格大于20米。应用与B3相同的圆盘外凸包函数后：

- 真源误删0次；
- 412个夹具的外包面积发生严格收缩；
- 最小失败距离20.020614米。

这些夹具检查数值实现；物理正确性来自更直接的蕴含 `clear失败 => ||g_c-q||>20`。凸包可能重新填回一部分已排除区域，因此它是安全但不一定最紧的表示。

两臂共记录28,422次失败清除事件。对每个事件重算真源距离和更新后的多边形包含关系，真源误排0。开启臂14,187次失败中9,992次使实际外包收缩；关闭臂轨迹上事后应用同一更新，14,235次中8,883次可收缩。事件在同一任务内重复出现，不能当作独立统计样本。

## 当前判断和边界

这一点适合写为“**动作失败也产生可证明的几何信息**”，并与上一轮的无线 `no_signal` 楔约束区分：这里来自20米光学清除半径，Q3/Q4都适用；无线无信号的可排除集合则随全向/定向物理模型不同。

它不适合写成显著提速点。当前B3中大多数配对轨迹完全相同，剩余差异很小；保守凸包也可能填回被圆盘切出的非凸缺口。完整案例已暴露，本轮没有新盲测或Windows官方执行。
