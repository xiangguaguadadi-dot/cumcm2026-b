# 第一问固定形式

后续主要迭代第三、四问。第一问固定为：半平面交求定位多边形 → 顶点最远距离求直径 → 用可由观测扇区实际产生的等边三角形否定“直径圆必覆盖”。

对每次观测，以检测点为顶点，取示向度±1度的两条边界射线并写成两个半平面。求全部半平面的交，先区分空集、无界和有界；不能把人为裁剪框造成的有界性当作观测本身的结论。对有界凸多边形枚举顶点对求最大欧氏距离。小规模交点枚举总复杂度O(n³+m²)；顶点多时可用旋转卡壳求直径。

反例：检测点(-1100,0)、(590,-550√3)、(570,570√3)，示向度1°、121°、241°，其±1°扇区恰交出边长40米的等边三角形。三角形直径40米，最小包围圆半径40/√3≈23.094米，半径20米的圆不能覆盖。因此“以区域直径为直径的圆”不总能覆盖定位区域。

保证20米清除范围应看最小包围圆半径≤20米；仅看区域直径≤40米不够。若只使用直径给充分条件，可要求直径≤20√3≈34.641米。
