# 第二至四问五项亮点：实际实验总报告

## 关键证据边界

亮点1和3只运行合成几何状态，没有新增完整任务world、公共轨迹回放或官方成绩。亮点1的36个条件中，28个使用既有单圆/分条几何，8个使用本轮新增递归扩展，报告已分开统计。

亮点2的固定21和固定22证书将实际binary64坐标转为整数后检查；固定21最小接收距离余量约0.109613米，固定22约0.001423米。普通浮点旋转坐标没有继承该整数证书。完整回归仍是已暴露本地案例，不是盲测或Windows官方执行；固定21也没有被证明为全局最少站点数。

亮点4的quick子集曾变慢，完整配对区间跨0，因此不能写成确定提速。最初观察器在近重复边上产生2次假阳性，修正后用2次实际重跑确认真源误排为0；原结果和勘误均保留。

亮点5的“同预算”指相同移动上限。每种误差界有18/80条件选择了更短实际移动；在其余62个等实际移动距离条件中，59个仍严格优于固定点。连续读数包络采用普通双精度和显式几何裕量，没有使用区间算术。

## 执行与审计

- 实际完整策略执行共8630次，全部正常全清：亮点2为3828次（full 3600、quick 180、纯几何压力48），亮点4为4802次（4800性能行及2次观察器确认）。其中quick为full子集，执行次数不能当作独立world数。
- 亮点2另有1440次单频道构造扫描。距离覆盖对照漏72/360，删外环对照漏168/360；两种认证布局均检出360/360。
- 亮点2的纯几何压力关闭全部源数捷径；48/48最终均由完整几何覆盖证书结束，逐频道实际 `no_signal` 记录齐全。
- 亮点1/3复核了92份光学计划、518个Voronoi子域、2818个覆盖顶点和3180个行动顶点。
- 亮点5独立复核480个合法点对与4000个圆/射线外包探针，无失败。
